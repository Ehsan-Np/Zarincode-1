# بانک تحقیقات (Researches)

حقیقت‌های کلیدی هر پژوهشِ انجام‌شده برای هسته، اینجاست و در پیشخوان ← «تحقیقات بازار» نمایش داده می‌شود.

- `rocket.php` — ZarinPal (درگاه، sandbox، REST) + جعبهٔ بهینه‌سازی ویرایش المنتور.
- `Bale_Research.php` — Bale (share + bot API).
- `Persianlabs_Icons.php`، `Social_IDEAA.php`، `Social_Signal.php` — مرجع آیکون‌های بار.
- `Zarincode_Theme.php` — زیرساخت قالب (Crextio/Webinex/afzoneha).

پس از هر پژوهشِ تازه، اینجا و صفحهٔ مربوطه را به‌روزرسانی کن (دستور دائمی: تحقیق ← نیازسنجی ← کدنویسی).
