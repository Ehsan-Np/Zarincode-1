Companion engine for the Zarincode theme, with 14 existing Elementor widgets and
six optional professional widgets. Native text editing preserves the original
layout. The theme includes a synchronized engine for legacy-plugin isolation.
PHP DOM is required for original-layout text extraction and inline annotation;
the site degrades safely without it. Elementor is required for widget editing.
WooCommerce is needed for shop functionality. No automatic demo imports.

== Installation ==
Back up and test on staging. Install zarincode-core.zip through WordPress Plugins.
Update the theme to the same release. Regenerate Elementor CSS and clear caches.
Do NOT reimport the demo when upgrading an existing site.
