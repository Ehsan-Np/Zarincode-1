# زرین کد ۳٫۵٫۰

توسعه‌دهنده: احسان نادری پناه — https://zarincode.com — 09024561001

برای ارتقا ابتدا بکاپ بگیرید و روی staging آزمایش کنید. فایل‌های قالب و افزونه
همراه را به‌روزرسانی، CSS المنتور را بازسازی و کش سایت را پاک کنید.
برای ارتقای سایت موجود **دمو را دوباره وارد نکنید**.

طراحی اصلی حفظ شده است. متن، آیکون، تصویر، پیوند، کارت‌ها و استایل اجزا از کنترل‌های
بومی Elementor به همان طراحی متصل‌اند. از تب محتوا یا کلیک روی متن استفاده کنید؛
کارت‌ها Repeater دارند و قوانین استایل اجزا در تب استایل‌اند. ذخیره با انتشار
Elementor انجام می‌شود. موتور طراحی اصلی به PHP DOM نیاز ندارد.
فهرست‌های تو‌در‌توی نامحدود یا Container مستقل برای هر جزء ادعا نشده است.
در ویجت تماس، شورت‌کد افزونه فرم واقعی قابل درج است؛ فرم اولیه نمایشی است.

شش ابزار جدید در دسته «زرین کد — ابزارهای حرفه‌ای آژانس» اختیاری‌اند و به صفحات
تزریق نمی‌شوند. فایل `demo-data/zarincode-professional-kit.json` را می‌توان از
بخش قالب‌های ذخیره‌شده Elementor وارد و در یک برگه آزمایشی درج کرد.
افزونه اصلی Xpro نیز از نصاب قالب به‌صورت اختیاری قابل دریافت است؛ برای ابزارهای
اختصاصی زرین کد لازم نیست. فعال‌سازی قالب، دمو یا Xpro را خودکار نصب نمی‌کند.
