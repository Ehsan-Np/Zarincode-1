# Xpro reference and optional integration

Source reviewed: https://github.com/wpxpro/xpro-elementor-addons
Revision: 7f2457547708ccf02623d15dec79ed9fcf211edc (Xpro / wpxpro contributors).
Reference widgets: icon-box, step-flow, progress-bar, before-after, team and table.

Zarincode's six new widgets are independent implementations of related widget
behaviour/concepts, using Elementor's public API, new PHP, native interactions and
new RTL CSS. No upstream PHP/JS, icons, photographs, bundled libraries, premium
features or remote template/tracking infrastructure are copied or loaded.

Upstream has inconsistent license labels: its LICENSE contains GPL v3 while its
readme.txt says GPLv2. COPYING-GPL-3.0.txt is retained as an unmodified reference
to the reviewed repository's license, not a claim that its code is bundled here.
The independently authored Zarincode code retains this project's GPL-2.0-or-later
license. Attribution is not an endorsement by Xpro.

For users who want the actual upstream addon collection, the theme plugin manager
provides an OPTIONAL WordPress.org download. It is not auto-installed and is not a
runtime dependency of any Zarincode widget. That separately downloaded plugin is
subject to its own current licenses and compatibility requirements. The GitHub
snapshot (from 2022) is not silently installed into customer websites.
