# نتایج اجرای ۳٫۱٫۰

۲۲ اکتبر ۲۰۲۶؛ محیط دورریختنی PHP 8.4.27، WordPress 7.1.3، Elementor 4.3.5، WooCommerce 11.2.1، SQLite و Chromium/Playwright.

## اجرای تازه روی کد اصلاح‌شده

- `native-design.php`: **۱۷۹۵ assertion، ۲۳ مدل** موفق.
- `restore-and-identity.php`: **۲۷۲ بررسی** موفق، بدون هشدار `_id` هنگام تولید CSS.
- `professional-inline.php`: **۹۷ بررسی** موفق.
- `wordpress-integration.php`: همه بررسی‌ها موفق؛ ثبت ویجت‌ها، کنترل‌ها، خروجی، CPT و idempotency دمو.
- `professional-kit.php`: ورود کیت، رندر شش ویجت و تولید CSS موفق.
- `icon-compatibility.php`: **۱۳۷ بررسی در ۲۰ نوع ویجت** موفق؛ آیکن قدیمی/جدید، نام نامعتبر، Repeater، پیش‌فرض/صدور و رندر.
- `icon-corrupt-data.php`: JSON تهی/خراب و فایل مفقود با error handler هشدار-به-استثنا موفق؛ بدون دستکاری vendor.
- `icon-warning-repro.php`: داده یکسان `fa-solid fa-circle-check` با `library=fa-missing` در ۳٫۰٫۰ هشدار دقیق `font-awesome.php line 45` را تولید کرد؛ روی کد جدید بدون آن هشدار رندر شد. این اصلاح محدود به ویجت‌های زرین کد است.
- lint **۶۶ فایل PHP** شامل آزمون‌ها و بررسی نحو editor.js موفق؛ هسته داخلی و مستقل بدون اختلاف.

## مرورگر و ذخیره واقعی

- `native-browser.cjs`: فیلتر scoped، فونت موبایل 24px، عرض 390/390، تغییر inline عنوان Hero و عنوان ردیف خدمات در مدل واقعی، انتشار و بازخوانی موفق؛ `PAGE_ERRORS []`.
- `professional-browser.cjs`: تغییر متن در طرح اصلی و Repeater حرفه‌ای، انتشار و تأیید frontend، مقایسه تصویر با input/کیبورد/drag اشاره‌گر، overflow موبایل و خطاهای مرورگر موفق.
- `editor-panel-browser.cjs`: پنل Hero ابتدا **۲ فیلد قابل‌دیدن از ۱۵۲**، یک بار بارگذاری editor.js، نمایش همه اجزا، جستجوی بی‌نتیجه و پاک‌کردن آن، حفظ مقادیر محتوایی موفق. بازکردن سربرگ بخش در این smoke با dispatchEvent است، نه اثبات pointer همه کنترل‌ها. نرمال‌سازی paragraph توسط TinyMCE در مقایسه معنایی متن لحاظ شده است.

دو مجموعه اول از کلیک/تایپ واقعی و ذخیره استفاده می‌کنند؛ مجموعه سوم آزمون فیلتر پنل است. این‌ها آزمون جامع تک‌تک کنترل‌ها، همه مرورگرها یا تمام ترکیب افزونه‌ها نیستند. baseline بصری کامل ۳٫۰ در این مرحله دوباره اجرا نشده است؛ آزمون حفظ طرح و مدل‌ها اجرا شده‌اند.

## کارایی و محدودیت

[داده‌های خام](benchmarks/3.1.0/) شامل سه درخواست هر نسخه روی نصب یکسان Woo فعال است. WP_ADMIN پیش از ساخت کنترل‌ها فعال و edit mode تنظیم شده تا خروجی واقعی metadata ادیتور اندازه‌گیری شود. اعداد و دامنه دقیق در [یادداشت انتشار](../RELEASE-3.1.0.md) آمده‌اند.

هشدار nullable قدیمی PHP 8.4 در `atomic-global-styles.php` خود Elementor در log بعضی آزمون‌ها باقی است؛ با خطای Font Awesome یکی نیست و مخفی نشده. MySQL/MariaDB، PHP 8.0، Safari/Firefox، پرداخت واقعی، ممیزی مستقل امنیتی و تأیید رسمی مارکت‌ها در این نوبت آزمایش نشده‌اند. legacy-upgrade در انتشار قبلی موفق بوده ولی این نوبت دوباره اجرا نشده است.
