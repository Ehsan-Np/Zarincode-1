## Defects found and corrected during QA
- The fresh Woo install initially enabled its guest coming-soon screen. This was disabled in the disposable database; the **final complete 216-case matrix was rerun with the actual storefront public**, and the linked-product destination verified. The QA fixture now explicitly disables coming-soon; production Woo settings are not changed by this release.
- Old product image wrapper forced height:auto/contain and light background; explicit fill geometry and dark backdrop now prevent a light bar under the overlaid title. Existing user-selected fit remains controllable.
- Global inline-size containment on Elementor inner containers inflated flex widget heights. It was removed: a small ResizeObserver helper measures actual container widths and writes stable state attributes without size containment. Mutation handling supports inserted Elementor widgets, and window-resize fallback is provided. Existing card-only container sizing from 3.7.4 is retained. No observer/browser page errors in final matrix.
- At minimum mobile width 280, a long footer contact button protruded 5px; footer labels now wrap inside their own box. Narrow-header controls can wrap rather than cause global scroll.
- Redux ignores a nonstandard display_menu argument; the official menu_type=hidden setting was tested instead. Legacy Redux routes require redirect before admin_init, because the hidden engine does not register a visible page.
