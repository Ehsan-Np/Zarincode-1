# آزمون ۳٫۵٫۰

محیط دورریختنی موجود: WordPress 7.1.3، Elementor 4.3.5، WooCommerce 11.2.1، PHP 8.4.27، SQLite و Chromium 156 / Playwright. کد جدید جدا از نتایج نسخه ۳٫۴ آزموده شد.

## PHP و داده
- `experience-3.5.php`: **۵۷ بررسی موفق**: URL و SVG مخرب/DTD/خالی/بزرگ، کلاس فونت خراب، حفظ توکن اشتراک، شناسه پایدار و یکتای ردیف‌ها، FAQ ایمن، inherit/custom/hide، تأیید/در انتظار/اسپم/زباله‌دان، اعتبار nonce و امتیاز، خانه خدمات‌محور بدون تکرار شماره و شش مقاله ساختاریافته.
- بررسی جداگانه: هر چهار حالت ستون؛ حذف aggregate وقتی دیدگاه مخفی است؛ احترام به فیلتر مالکیت schema افزونه SEO.
- رگرسیون‌ها: **۲۰۳۶** native-design؛ **۵۵** dynamic-content؛ **۳۵۳** restore/identity؛ **۱۰۰** professional-inline؛ **۱۴۷** icon compatibility؛ **۲۹** studio؛ **۶۴** editorial 3.4، همگی موفق.
- `wordpress-integration.php`: تمام بررسی‌ها و تکرار درون‌ریزی موفق؛ `demo-coverage.php`: **۲۷ نوع فعال** در صفحات مرتبط. کیت مستقل: import و رندر شش ویجت و تولید CSS موفق.
- lint **۷۵ فایل PHP** قالب/هسته موفق؛ syntax دو JS مدیریتی جدید موفق.
- دموی WXR **۷۸ رکورد**؛ فقط ترم‌های استفاده‌شده و والدهایشان؛ بدون localhost، حساب تست و ترم QA. دیدگاه‌ها و متادیتای شمارش نقد/امتیاز/فروش محیط تست صادر نمی‌شوند.

## مرورگر جدید: `browser-3.5.cjs`
- خانه با ظاهر روشن یکدست، monogram ZC و فهرست شناور شبکه‌ها.
- دو ستون در جای فیزیکی درست RTL؛ نمایش محصولات واقعی منتشرشده و آیکون SVG دلخواه پاک‌سازی‌شده در اشتراک.
- بازخورد واقعی کپی نشانی کوتاه.
- خانه، مقاله، محصول، خدمات و تعرفه در عرض‌های **۱۵۶۰، ۱۲۸۰، ۱۰۲۴، ۷۶۸ و ۳۹۰** بدون سرریز افقی.
- **ارسال واقعی دیدگاه چهارستاره از فرم وردپرس** و مشاهده امتیاز/BlogPosting aggregate در صفحه بعد.
- **افزودن، ذخیره و رندر واقعی شبکه از صفحه مدیریتی بومی** با فونت Discord.
- **ویرایش واقعی محصول در مدیریت**، انتخاب سیاست اختصاصی، ذخیره سؤال/پاسخ و باز کردن آکاردئون در نمای عمومی.
- هیچ `pageerror` در مسیرهای آزموده‌شده ثبت نشد. screenshots: `home-3.5.png`، `article-3.5.png`، `product-policy-3.5.png`.
- بررسی مکمل: تصویر PNG با API بومی رسانه ثبت شد، بارگیری lazy آن بعد از اسکرول واقعاً کامل شد؛ رنگ محاسبه‌شده سربرگ مقاله با پالت تاریک مطابقت داشت. مسیر upload از پنجره رسانه به‌صورت end-to-end آزموده نشد.

## محدودیت‌ها
- هشدار nullable متعلق به Elementor روی PHP 8.4 همچنان در خروجی CLI هست؛ ادعای لاگ vendor کاملاً پاک نداریم.
- CLI import تصویر به دلیل نبود GD/Imagick متوقف شد؛ آزمون PNG از API عادی وردپرس و تصویر اصلی، بدون تولید thumbnail، انجام شد. محیط تولید برای پردازش کامل تصاویر باید GD یا Imagick داشته باشد.
- آزمون جدیدی روی Safari/Firefox، MySQL، PHP 8.0، ویرایشگر آزمایشی بلوکی محصول Woo، پرداخت واقعی، درون‌ریزی WXR روی نصب مستقل یا نمایش ستاره در گوگل انجام نشده است.
- schema به صورت JSON و ارتباط با داده واقعی بررسی شد؛ Google review snippet برای Article/BlogPosting پشتیبانی نمی‌شود. هیچ ارزیابی امنیتی/حقوقی/تأیید مارکت مستقل ادعا نمی‌شود.
