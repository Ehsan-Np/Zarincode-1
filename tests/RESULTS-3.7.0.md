# آزمون Zarincode 3.7.0

محیط واقعی آزمون: WordPress **7.1.3**، WooCommerce **11.2.1**، Elementor **4.3.5**، PHP **8.4**، پایگاه SQLite و Chromium/Playwright. داده‌های QA موقت‌اند و وارد WXR و کیت دموی قابل انتقال نشده‌اند.

## آزمون‌های جدید
- `browser-3.7.cjs`: **۸۰ assertion موفق**؛ ورود واقعی مشتری، nonce فرم‌های ورود/بازیابی/ویرایش، منوی حساب، سفارش متعلق به مشتری، جزئیات، دانلود مجاز، آدرس‌ها/فرم billing و shipping، اطلاعات حساب، حالت‌های بومی روش پرداخت/افزودن آن، رد سفارش مشتری دیگر و ذخیره واقعی اطلاعات کاربر.
- بدون سرریز افقی در پیشخوان، سفارش‌ها، دانلود، billing و اطلاعات حساب در عرض‌های **۱۸۰۰، ۱۴۴۰، ۱۰۲۴، ۷۶۸، ۳۹۰ و ۳۶۰px**.
- مختصات دکمه‌های شناور پیش و پس از اسکرول واقعی نسبت به viewport ثابت ماند؛ کلیک بازگشت به بالا واقعاً scrollY را به صفر رساند.
- ستاره‌ها پنج radio بومیِ بدون فاصله‌اند؛ کلیک، کلید Space/ArrowRight، بازخورد انتخاب و پاک کردن انتخاب کار می‌کنند. اندازه آیکون اشتراک ۳۲×۳۲ و کپی واقعی همراه بازخورد تأیید شد.
- تصویر اصلی و گالری واقعاً بارگذاری شدند؛ **نه فقط naturalWidth، بلکه مختصات اسلاید اول و دوم داخل قاب** سنجیده شد. بندانگشتی و lightbox بومی ووکامرس باز شدند. یک باگ جهت RTL در همین بررسی پیدا و اصلاح شد.
- پیوند سفارشی حساب در **هدر اصلی و هدر بومی Elementor** عیناً درست رندر شد؛ هیچ pageerror در مسیرهای آزمون مرورگر اصلی ثبت نشد.

### عملیات واقعی حساب (`account-flows-3.7.cjs`)
- انتخاب کشور ایران/استان تهران، POST بومی آدرس و تأیید مقدار ذخیره‌شده در متای کاربر.
- دریافت فایل از لینک مجاز حساب با HTTP 200 و بررسی **محتوای واقعی فایل**.
- خروج واقعی از لینک nonceدار ووکامرس و بازگشت به فرم ورود.
- کلید بازنشانی تولیدشده با API وردپرس، کوکی/فرم/nonce بومی ووکامرس، ثبت رمز جدید و تأیید آن با `wp_check_password`.
- ثبت‌نام با فعال‌سازی موقت تنظیم ووکامرس: وجود فرم اصلی، nonce و ظاهر دو ستونه/تک‌ستونه در دو عرض. **ارسال فرم ثبت‌نام و تحویل ایمیل ثبت‌نام آزموده نشده‌اند.** تنظیم اولیه پس از آزمون برگردانده شد.

### رسانه و سازگاری
- `commerce-3.7.php`: **۶۵ بررسی موفق**؛ هشت variant کارت × رسانه ID-only / URL-only / بدون تصویر، پیوند واقعی تصویر، منبع خودکار، استفاده از گالری هنگام نبود تصویر شاخص، URL دلخواه/داخلی، رد javascript/data، خاموش کردن CTA، خروج nonceدار و حفظ قالب‌های عملیاتی Woo در پلاگین.
- `gallery-widgets-3.7.cjs`: هر دو اسلاید در **RTL واقعی Woo** داخل قاب بودند؛ تصویر واقعی و permalink محصول ابزارک، حرکت کاروسل و نبود سرریز در **۱۴۴۰/۷۶۸/۳۹۰px** موفق.
- `rating-submit-3.7.cjs`: POST واقعی نظر اصلی از ستاره‌های جدید، ذخیره امتیاز **۴** با والد **۰**، وضعیت تأیید و نمایش ستاره‌ها موفق.
- patch تولید مدل‌های ۳٫۷ به‌صورت مستقل **idempotent** و از نظر ساختار با مدل‌های جاری برابر بود. تغییرات در runtime نیز بدون DOM parser/تزریق جاوااسکریپت هدر انجام می‌شود.

## رگرسیون
- مرورگر **۳٫۶** روی کد جدید: ارسال واقعی پاسخ سطح دو/سه و لغو در نوشته، محصول، خدمت، پروژه و برگه؛ **۶۴ سنجش هندسی** هدر/بدنه/فوتر در دو نوع هدر، دو عرض تنظیمی و چهار حالت ستون و چهار عرض مرورگر؛ اشتراک/کپی همگی موفق. تصاویر تاریخی ۳٫۶ پس از آزمون بازیابی شدند.
- PHP: **۱۵** discussion/security، **۵۷** experience، **۶۴** editorial، **۲۰۳۶** native-design در ۲۶ چیدمان، **۵۵** dynamic-content، **۳۵۳** restore/identity، **۱۰۰** inline، **۱۴۷** icons و **۲۹** studio موفق.
- lint تمام **۸۱** فایل PHP قالب/core شامل mirror؛ syntax سه فایل JS تغییرکرده، `git diff --check` و همسانی دقیق EmbeddedCore/standalone بررسی شد.
- بسته‌ها از سورس همین نسخه ساخته و تک‌تک ورودی‌های ZIP با سورس مقایسه شدند؛ SHA-256 تازه تولید شد. XML و کیت دمو بدون تغییر باقی ماندند.

## بازتولید در staging موقت
Fixtureهای این پوشه برای سایت زنده نیستند. آن‌ها مشتری/محصول/سفارش/برگه موقت و فایل دانلود ایجاد می‌کنند؛ کلیدهای ورود فقط در `/tmp/zc37-private.json` با مجوز 0600 قرار می‌گیرند. مسیر WP و Playwright در اسکریپت‌ها مربوط به staging این پروژه است.

```sh
php /tmp/wp-cli.phar --path=/tmp/wordpress eval-file tests/fixture-3.7.php
php /tmp/wp-cli.phar --path=/tmp/wordpress eval-file tests/widget-fixture-3.7.php > /tmp/zc37-widgets.log
php /tmp/wp-cli.phar --path=/tmp/wordpress eval-file tests/commerce-3.7.php
NODE_PATH=/tmp/zc-browser/node_modules node tests/browser-3.7.cjs
NODE_PATH=/tmp/zc-browser/node_modules node tests/gallery-widgets-3.7.cjs
NODE_PATH=/tmp/zc-browser/node_modules node tests/account-flows-3.7.cjs
# برای rating-submit-3.7.cjs رمز مدیر آزمایشی را در ZC_TEST_ADMIN_PASSWORD بدهید.
```

## مرز آزمون
پرداخت واقعی، tokenization یا مدیریت کارت درگاه ثالث آزموده نشده‌اند؛ تست روش پرداخت، shell و حالت‌های مجاز/خالی Woo نصب‌شده را پوشش می‌دهد. ایمیل محلی sendmail ندارد؛ reset از کلید معتبر API آزموده شد، نه تحویل ایمیل. Safari، Firefox، MySQL، PHP 8.0 و همه افزونه‌های account/هدر ثالث آزموده نشده‌اند. اعلان nullable متعلق به vendor Elementor در CLI باقی است و پاکی کامل لاگ vendor ادعا نمی‌شود. زبان فرم‌های بومی تابع زبان نصب/ترجمه Woo است. تصاویر fixture نمایش‌دهنده مشتری یا محصول تجاری تازه نیستند؛ تأیید مارکت‌پلیس یا نمایش ستاره Article در نتایج گوگل ادعا نمی‌شود.
