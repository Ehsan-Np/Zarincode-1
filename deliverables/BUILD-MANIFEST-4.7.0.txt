Zarincode 4.7.0 build manifest
=============================
Date: 2026-11-09
Builder: workspace sandbox (manual zip recipe; build-release.py still stale)

Goal of this release
--------------------
1) Fix the demo-import error reported from the live site (debug.log) and every
   PHP notice found with it.
2) Make the 11 homepage widgets behave like stock Elementor widgets: real,
   filled-in content controls, a Style tab with colors/typography/spacing/
   border/shadow, and an icon picker instead of a free-text icon name.

Known limits / notes
--------------------
* Style defaults are intentionally empty: the shipped CSS keeps defining the
  design until a user overrides a value, so existing pages do not change.
* The 4.6.0 zips were removed from deliverables/ to keep the folder at exactly
  two archives; they remain downloadable from the v4.6.0 tag in git history.
* build-release.py is still stale; the zips were built with the documented
  manual recipe (zip -qr from each package root, unzip -t verified).
