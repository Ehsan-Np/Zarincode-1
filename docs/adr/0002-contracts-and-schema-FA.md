# ADR-0002: قرارداد ویجت و نسخه‌بندی بدون بازنویسی داده

- مسئله: مشخصات کیفیت، schema و بودجه برای ۲۶ ویجت یکجا قابل خواندن نبود.
- زمینه: IDها و repeater identityها نباید عوض شوند؛ هیچ تست بصری جامعی برای تمام ویجت‌ها موجود نیست.
- گزینه‌ها: تولید امتیاز تخمینی؛ لایه‌های کارخانه و interface متعدد؛ metadata کوچک و API خالص و صریح.
- تصمیم: یک registry قرارداد خواندنی از IDهای واقعی و یک trait مشترک برای سه پایهٔ ویجت. وضعیت اولیه `Not Reviewed` و Z-WQI برابر null است؛ آزمون وجود metadata معادل تأیید کیفیت نیست. `Settings_Schema::upgrade` API صریح و opt-in است، خودکار روی محتوای مشتری اجرا نمی‌شود، ID و فیلدهای ناشناخته را حفظ و نسخهٔ آینده را رد می‌کند.
- پیامد: ساختار قابل‌آزمون بدون container یا factory اضافه؛ workflow مهاجرت گسترده، backup/restore و UI پیشرفت هنوز پیاده‌سازی نشده‌اند و ادعا نمی‌شوند.
- معیار بازنگری: اولین تغییر واقعی schema یک ویجت یا نیاز به مهاجرت دادهٔ ذخیره‌شده.
