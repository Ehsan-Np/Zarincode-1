# ADR-0001: مالکیت مستقل runtime در افزونه همراه

- وضعیت: پیاده‌سازی‌شده در نامزد انتشار؛ تأیید کل محصول نیست.
- تاریخ: ۲۰۲۶-۱۰-۲۲
- مسئله: افزونه کلاس‌های خود را از EmbeddedCore قالب می‌خواند و فعال‌شدن قالب می‌توانست فایل افزونه را بازنویسی کند؛ تعویض قالب و نسخه‌بندی مستقل قابل اتکا نبود.
- زمینه: ID ویجت‌ها و کلاس‌های Runtime260، CPTها، متا و گزینهٔ `zarincode_opt` از قبل در سایت‌ها ذخیره شده‌اند.
- گزینه‌ها: حفظ اولویت قالب؛ همگام‌سازی دائمی دو نسخه؛ مالکیت واحد افزونه و نصب صریح.
- تصمیم: افزونه فقط از `includes/` خودش autoload می‌کند. نسخهٔ تکراری تنها بعد از تأیید برابری بایت‌به‌بایت از قالب حذف شد. Bootstrap قالب فقط کلاس‌های presentation خودش را بارگذاری می‌کند. نصب/فعال‌سازی/به‌روزرسانی افزونه صریح است؛ theme activation هیچ دانلود یا کپی خودکاری ندارد.
- پیامد: برای ویجت‌ها و CPTها باید companion جداگانه نصب و فعال باشد؛ قالب بدون آن تنها قابلیت‌های بومی و fallback خود را نمایش می‌دهد. خاموش‌کردن افزونه داده را حذف نمی‌کند. ظاهر کامل ویجت‌ها در تمام قالب‌های ثالث ادعا نشده؛ وابستگی برخی رسانه‌های پیش‌فرض و توکن‌های ظاهری هنوز در backlog است.
- سازگاری: namespace و شناسه‌های Elementor/CPT و کلیدهای تنظیمات تغییر نکرده‌اند. نسخهٔ major نامزد `4.0.0-rc.1` به‌دلیل تغییر قرارداد نصب انتخاب شده است.
- معیار بازنگری: تغییر API پایدار، انتشار افزونه بدون نیاز به دارایی تصویری قالب، یا شکست آزمون تعویض قالب.
- آزمون: reflection مسیر کلاس، تعویض واقعی به Twenty Twenty-Five، درخواست مستقل پس از تعویض، قالب بدون افزونه، حفظ محتوا و متا.
