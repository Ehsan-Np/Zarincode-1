# بازگرداندن «شکل قبلی» جدول لیست قیمت — ۲۰۲۶-۱۰-۳۱

## شکایت و تصمیم

کاربر (دو بار، با اعتراض): «جدول لیست قیمت، همون شکل قبلی باید باشه». پرسش انتخاب شکل از کاربر
**رد شد (skipped)**، بنابراین بدون پرسش مجدد، تصمیم بر اساس شواهد مخزن گرفته شد:

1. پاسخ تأییدشدهٔ قبلیِ خود کاربر: «مثل صفحهٔ تعرفه خدمات (پلن‌های قیمت + جدول امکانات)».
2. ساختار مرجعِ موجود در همین مخزن = آیتم صفحهٔ `pricing` در WXR:
   `heading(H1) + zarincode_pricing + zc-pricing-composition (۳ کارت پلن) + zarincode_service_matrix`.
3. سایت زندهٔ zarincode.com اکنون 404 است و Wayback فقط نسخهٔ قدیمیِ پیش-وردپرس را دارد؛
   مرجع قابل‌اتکا همان صفحهٔ تعرفهٔ داخل مخزن است.

نتیجه: **نوار قیمتِ صفحهٔ اصلی = عینِ ترکیبِ صفحهٔ تعرفه** (با تگ عنوان h2 به‌جای h1).

## شواهد ساختاری (بررسی خودکار روی WXR بازشده)

1. **نوار قیمت خانه == بدنه صفحه تعرفه** (به‌جز تگ h2/h1 و شناسه‌های تصادفی): `True` — بایت‌به‌بایت با نرمال‌سازیِ دو تفاوت مجاز.
2. **تنظیمات ویجت لیست قیمتِ جدید == تنظیمات قدیمی (۴۱ کلید)**: `True` — «شکل قبلی» دقیقاً حفظ شد.
3. **تنظیمات نوار خانه == تنظیمات قدیمی صفحه تعرفه**: `True`.
4. **سه کارت پلن خانه == سه کارت پلن صفحه تعرفه**: `True`.
5. **بقیه ویجت‌های خانه (خارج از نوار) نسبت به commit قبلی**: نوع و محتوا یکسان؛ تنها دو دسته تفاوتِ اصلاحی:
   - `&amp;` → `&` (رفع دوباره‌کدگذاریِ entity در برچسب‌ها/کارت‌ها: «TOOLS &»، «PHP 8.4 & Laravel»، «Ready-Made Themes, Plugins & Source Codes» و…) — نمایش نهایی یکسان است؛
   - URL تصاویرِ `why_us` به‌جای `zarincode.com/wp-content/...` (که اکنون 404 است) به `raw.githubusercontent.com/.../assets/images/...` (الگوی استانداردِ exporter) — لینکِ کارامد.

ترتیب خانه پس از تغییر:
`hero → brands → services → steps → portfolio → why_us → heading(h2) → zarincode_pricing → زc-pricing-composition(۳ پلن) → service_matrix → blog → promo`

- `home-fullpage.png` — صفحهٔ اصلی، کامل
- `pricing-fullpage.png` — صفحهٔ تعرفه، کامل
- `proof-home-vs-pricing-side-by-side.png` — نوار قیمت خانه (چپ) کنار صفحهٔ تعرفه (راست): عنوان، تب‌ها، ۶ کارت پلن (قیمت‌ها، نشان‌ها، دکمه‌ها) و جدول ماتریس **یکسان**؛ تفاوت فقط تگ عنوان و هِدِر سایت است.
- تطبیق پیکسلی نوار با صفحهٔ تعرفه: MAE اولیه ~۳۴ (ناهم‌ترازیِ انتهای باند) با **۱۲۰۰/۲۶۰۰ ردیفِ تقریباً یکسان**؛ هم‌ترازیِ کامل از بررسی بصری side-by-side تأیید می‌شود.
