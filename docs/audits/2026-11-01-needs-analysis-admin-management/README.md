# نیازسنجی مدیریت پیشخوان — چرخهٔ ۲۰۲۶-۱۱-۰۱ (v4.1.1)

سند «نیازسنجی + کدنویسی» طبق دستور دائمی کاربر: **تحقیق ← نیازسنجی ← مرور همهٔ پرامپت‌ها ← کدنویسی**.
تمام الزامات پیام ۲۰۲۶-۱۱-۰۱ کاربر و پرامپت‌های قبلی (`docs/prompts/*.md`) اینجا فهرست شده و وضعیت پیاده‌سازی مشخص است.

## ۱) گفتگوی آنلاین (Chat) — «حتماً یک محیط گفتگو در پیشخوان»

| نیاز | وضعیت | محل/شواهد |
| --- | --- | --- |
| محیط گفتگو در پیشخوان ← «گفتگوهای زنده» (زیرمجموعهٔ زرین‌پرس) | ✅ | `Features/Live_Chat.php` — فهرست مخاطبان، وضعیت آنلاین/آفلاین، خوانده‌نشده‌ها |
| پاسخ مدیر به کاربر (متن + فایل) | ✅ | نمای thread با فرم پاسخ + آپلود فایل |
| **گفتگوی زنده (زنده‌بودن واقعی)** | ✅ NEW | پولر ۸ ثانیه‌ای در صفحه‌های فهرست/thread (`zc_chat_admin_poll`)؛ تازه‌سازی خودکار + نشانگر سبز/خاکستری |
| **تنظیمات کامل چت** (صفحهٔ «تنظیمات گفتگو») | ✅ NEW | فعال/غیرفعال کل چت، عنوان پنل، خوش‌آمدگویی، پیام آفلاین، متن نوشتن، رنگ تم |
| فعال/غیرفعال‌سازی فیلدها (نام/موبایل/وبسایت) | ✅ NEW | `chat_field_name/phone/website` — موبایل خاموش ← تاریخچه با IP؛ نام خاموش ← «مهمان» |
| ارسال فایل/عکس/ویدیو/ویس با تنظیم حجم و قالب‌ها | ✅ (کامل‌تر) | `chat_allow_photo/video/voice` + `chat_max_mb`(۱–۶۴)؛ `accept` و راهنمای حجم در UI |
| شخصی‌سازی ظاهر ویجت | ✅ NEW (پایه) | رنگ تم (`--zc-chat-accent`) + عنوان/متن‌ها؛ توسعهٔ بعدی: موقعیت و قالب |
| تشخیص آنلاین/آفلاین مدیر (بدون وابستگی به باز بودن پنل) | ✅ | حضور با ۹۰ ثانیه آخرین فعالیت پیشخوان/فرانت |
| تاریخچهٔ کامل به تفکیک موبایل/IP | ✅ | CPT‌های `zc_chat_contact` + `zc_chat_message` |

**نکتهٔ کلیدی برای مدیر**: پیام‌های کاربر در **پیشخوان ← زرین‌پرس ← گفتگوهای زنده** است؛ فرم «مشاورهٔ رایگان» جداگانه در «درخواست‌های مشاوره».

## ۵) بک‌لاگ (سیکل مستقل، «وقتی درخواست شد»)

- **سیستم تیکت/پشتیبانی**: طبق دستور کاربر فقط پس از درخواست + جستجوی پلتفرم‌های آنلاین. طراحی پیشنهادی (زمان درخواست): صف/دسته‌بندی، SLA، وضعیت‌ها، اتصال به چت و فرم‌ها.
- شخصی‌سازی عمیق‌تر ویجت چت (قالب/موقعیت/لوگو).
- Element Manager: افزونهٔ جانبی برای غیرفعال‌سازی خودکار ویجت‌های بلااستفاده (فعلاً راهنما).
