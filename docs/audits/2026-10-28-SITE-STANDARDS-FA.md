# یکپارچگی عرض، فونت، مدیریت و سئوی فنی

## دامنه واقعی این تغییر

این چرخه، اصلاح هدفمند زیرساخت مشترک و ممیزی تمام کنترل‌های اعلام‌شده پنل است؛ **بازنویسی کامل تمام مدل‌ها، محتوا، فرم‌ها و درون‌ریز و تأیید کامل سایت نیست**. Release قبلی `v4.0.0-rc.2` خودکار تغییر نکرده و این اصلاحات با انتشار قبلی یکسان معرفی نمی‌شوند.

## اصلاحات اجراشده

### هندسه مشترک

- `site-contract.css` برای پوسته‌های `.zc-container`، `.zc-edit`، `.zc-pro` و ترکیب هیرو؛ width، max-width، box-sizing، حاشیه مرکزی و gutter منطقی مشترک.
- رعایت safe area؛ حذف gutter تکراری داخل هیرو و پوسته‌های تودرتو.
- رفع محدودیت اضافی والدهای boxed المنتور که میزبان ویجت بومی زرین‌کد هستند؛ طرح‌های دلخواه full-bleed و ویجت‌های بی‌ارتباط عمداً بازنویسی نمی‌شوند.
- عرض متن مطالعه محدودتر از پوسته بیرونی می‌تواند باقی بماند؛ لبه‌های پوسته کامل همراه سایدبار با هدر و فوتر مقایسه شده‌اند، نه ستون متن تنها.
- عرض‌های دستی موجود، مقیاس ۱۰۸٪ و breakpointهای تنظیمات حفظ شده‌اند؛ عرض دستی مجدداً ضرب نمی‌شود.

### اعلان نصب

- کلیک روی ضربدر، انتخاب را با AJAX و nonce در user meta ذخیره می‌کند؛ هر مدیر انتخاب مستقل دارد.
- مسیر POST محافظت‌شده و دکمه «دیگر نمایش نده» برای حالت بدون JS.
- کنترل capability و nonce؛ ورودی کاربر، شناسه مدیر دیگری را انتخاب نمی‌کند.
- شکست ذخیره‌سازی از کاربر پنهان نمی‌شود؛ اعلان جایگزین و مسیر POST باقی می‌ماند.

### تایپوگرافی

- خانواده فعلی و تنها انتخاب پشتیبانی‌شده در پنل **Vazirmatn / وزیرمتن** است؛ فایل‌های WOFF2 هفت وزن قبلاً در سورس موجود بودند و حفظ شده‌اند.
- فراخوانی مشترک فونت در WordPress admin و editor المنتور، استایل متون مدیریت، متون/عنوان‌های فرانت و کنترل‌های فرم.
- اولویت فونت متن نسبت به Tahoma/Arial پراکنده؛ حفظ Font Awesome، Dashicons، eicon و فونت monospace کدها.
- صفحه تعمیر نیز فونت محلی می‌گیرد. تنها وزن Regular به‌صورت critical preload است؛ وزن‌های دیگر هنگام نیاز با `font-display:swap` دریافت می‌شوند.
- «۱۰۰٪ متن‌ها در تمام افزونه‌های ثالث» تأیید نشده است؛ فونت آیکن نباید به فونت متن تبدیل شود. بارگذاری بدون fallback موقت در شبکه قطع‌شده یا روی هر دستگاه ادعا نمی‌شود.

### تنظیمات

- ۱۵۷ کنترل در ۱۸ بخش استخراج و فهرست مصرف‌کننده ایستا برای همه ثبت شد؛ جدول کامل در `2026-10-28-settings-inventory.md`.
- اعتبارسنجی رنگ، URL رسانه، عدد، مقدار select، ارتفاع خط و اندازه فونت؛ محدودیت تعداد نتایج و عرض.
- حفظ HTML نشان‌های اعتماد برای عبور از renderer امن موجود؛ حفاظت قابلیت unfiltered_html برای کدهای سفارشی حفظ شده است.
- ورودی Import خالی/بدشکل دیگر به مسیر Save سقوط نمی‌کند؛ اکشن ناشناخته گزینه‌ها را ذخیره نمی‌کند.
- CSS تمام‌عرض پنل به صفحات زرین‌کد محدود شد تا پنل‌های Redux افزونه‌های دیگر را دستکاری نکند.
- رفع ابزار رنگ همیشه‌فعال و جایگزین‌کردن پالت/حالت پیش‌فرض مدیر با زرد/روشن از JS؛ انتخاب معتبر قبلی بازدیدکننده در حالت فعال ابزار حفظ می‌شود.
- اتصال ستون‌های خدمات و وبلاگ به CSS؛ اتصال نمایش زمان مطالعه و باکس نویسنده، جدول شرایط/فرم/خدمات مرتبط و پیش‌فرض پیش‌پرداخت/گارانتی خدمت.
- حفظ اولویت متای اختصاصی خدمت بر پیش‌فرض عمومی؛ داده‌های ذخیره‌شده کاربران مهاجرت تخریبی ندارند.

**مانع باز:** همه کنترل‌ها مصرف‌کننده کامل ندارند. متن‌های هیرو، برخی تنظیمات نمونه‌کار/تعرفه، گیرنده ایمیل فرم، اطلاعات تماس و متغیرهای حقوقی نیازمند اتصال جداگانه و تست هستند. وجود مرجع متنی نیز اثبات عملکرد صحیح نیست. فرم‌های نمایشی قدیمی به endpoint ارسال واقعی تبدیل نشده‌اند. قالب‌های سفارشی المنتور می‌توانند متون و تنظیمات مستقل داشته باشند. تأیید عملکرد تمام امکانات پنل در این چرخه داده نمی‌شود.

### SEO و Schema.org

- canonical خودارجاع صفحه‌بندی به‌جای ارجاع همه صفحات آرشیو به صفحه اول؛ مسیر برگه وبلاگ، فروشگاه و آرشیوهای زمانی نیز در نظر گرفته شد.
- استفاده از canonical هسته برای singular، ادغام robots با فیلتر هسته به‌جای تگ تکراری.
- noindex مسیرهای تراکنشی/حساب، جستجو، 404 و محتوای رمزدار؛ عدم افشای excerpt رمزدار در metadata.
- رعایت مالکیت Yoast/Rank Math/AIOSEO؛ عدم معرفی sitemap هسته در حالت خصوصی/غیرفعال یا زمانی که افزونه SEO مالک است.
- entity سازمان با شناسه ثابت Organization به‌جای LocalBusiness/ProfessionalService بدون آدرس معتبر؛ اتصال Service و CreativeWork صفحات خدمت/پروژه به همان شناسه.
- زبان BCP-47 در JSON-LD (`fa-IR`)، حفظ locale Open Graph با underscore.
- حذف SearchAction غیرضروری؛ بدون ادعای Sitelinks Search Box گوگل.
- بدون امتیاز، review، offer یا آدرس ساختگی؛ اسکیمای Product همچنان در مالکیت ووکامرس است. افزودن نوع Schema به معنی تضمین Rich Result یا رتبه نیست.
- صفحه تعمیر: 503 همراه no-cache و Retry-After؛ بدون تغییر محتوا و داده‌های منتشرشده.

## سرعت: چه چیزی اندازه‌گیری نشده است؟

هیچ گزارش واقعی GTmetrix، PageSpeed Insights، Lighthouse سایت نصب‌شده یا داده CrUX در این چرخه تولید نشده است. امتیاز، LCP، INP، CLS و TTFB واقعی ادعا نمی‌شود.

تغییر فنی محدود: یک preload فونت به‌جای دو، حفظ بارگذاری محلی/swap، تصویر اصلی مقاله با سایز responsive `large` و `fetchpriority=high`، eager و decoding async؛ کم‌کردن CSS مدیریتی بی‌ارتباط. lazy-load عمومی تصاویر بالای صفحه یا حذف کورکورانه اسکریپت‌های WooCommerce/Elementor انجام نشده است.

برای تأیید: staging با محتوای واقعی، تست سرد/گرم حداقل سه‌بار در موبایل و دسکتاپ، وضعیت CDN/کش/فشرده‌سازی/بسته‌های سرور، DB، تصاویر و افزونه‌های ثالث؛ بررسی trace و درخواست‌های مسدودکننده. هدف خوب Core Web Vitals در صدک ۷۵: LCP ≤۲٫۵s، INP ≤۲۰۰ms، CLS ≤۰٫۱؛ این اعداد **هدف‌اند نه نتیجه اندازه‌گیری این پروژه**.

## آزمون‌های اجراشده

- PHP 8.5.10 واقعی از WebAssembly/WordPress Playground روی Node در محیط موقت: **۲۹۹ assertion** و parse تمام **۸۴ فایل PHP سورس**. APIهای WordPress در آزمون double هستند؛ این یک نصب WordPress نیست.
- Chromium headless: **۱۲۷ assertion**، ۷ عرض ۳۲۰/۳۹۰/۶۰۰/۷۶۸/۱۰۲۴/۱۴۴۰/۱۹۲۰ × RTL/LTR؛ هم‌ترازی لبه داخلی/خارجی پوسته‌ها، عدم gutter تکراری در wrapperهای classic/flex المنتور، بازیابی اعلان در شکست ذخیره، load واقعی فایل فونت، حفظ آیکن/کد، پالت/حالت مدیر، خاموشی ابزار رنگ و درخواست ذخیره اعلان.
- رگرسیون قبلی PWA/موبایل: **۷۲ assertion** موفق.
- قواعد معماری scoped موجود موفق؛ ۶ تست قرارداد ممیزی و ۶ تست محافظ ساخت بسته موفق.
- syntax check JS و diff whitespace موفق.

بازاجرا با PHP CLI و ابزار قفل‌شده مرورگر موجود پروژه:

```sh
php tools/qa-site-contract.php
python3 tools/audit-settings.py
NODE_PATH=tools/browser/node_modules node tools/qa-site-contract.cjs
NODE_PATH=tools/browser/node_modules node tools/qa-mobile-pwa.cjs
```

اسکریپت‌های browser به Chromium نصب‌شده Playwright یا `CHROMIUM_EXECUTABLE_PATH` نیاز دارند. پکیج موقت Chromium/PHP در وابستگی runtime پروژه اضافه نشده است. هیچ تغییری به workflow بدون مجوز GitHub اعمال نشده است.

## پیش از تأیید کامل/انتشار بعدی

۱. تکمیل کنترل‌های بدون اتصال در inventory؛ ارسال واقعی فرم و هماهنگی متن‌های عمومی با ویجت‌های ذخیره‌شده.
۲. آزمون Native/Redux Save/Reset/Import، media picker، کنترل capability و عدم regression با WooCommerce/Elementor واقعی و چیدمان‌های موجود سایت.
۳. آزمون اعلان پس از reload در دو حساب مدیر و حالت no-JS در WordPress واقعی؛ آزمون موبایل واقعی و zoom ۲۰۰٪.
۴. Rich Results Test و Schema validator روی URLهای عمومی واقعی؛ بررسی canonical و pagination، Search Console و robots/sitemap.
۵. PageSpeed/GTmetrix واقعی، تحلیل waterfall و CWV؛ بدون تضمین امتیاز ثابت.
۶. ساخت بسته جدید از کامیت تمیزِ تأییدشده؛ فایل‌های انتشار قبلی تغییر داده نشوند و با اصلاحات جدید اشتباه نشوند.
