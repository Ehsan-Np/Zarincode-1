# نمونه‌کارها — اصلاح موبایل و صفحه داخلی rc.6

## تغییر

- فیلتر نمونه‌کارها در عرض کمتر از ۷۶۸px به نوار تک‌ردیفه RTL قابل اسکرول، کارت کم‌ارتفاع با گوشه ۱۶px، دکمه‌های حداقل ۴۴px، وضعیت فعال زرد و focus مشخص تبدیل شد. selector فقط نمونه‌کارها را هدف می‌گیرد؛ فیلتر محصول/قیمت و طرح دسکتاپ تغییر نمی‌کند. data-filter و کنترلر موجود حفظ شدند؛ نوار تب جعلی ARIA اضافه نشده است.
- شناسنامه و محتوای اصلی پروژه حفظ و با زبان بصری محصول ترکیب شدند: breadcrumb، عنوان/دسته/خلاصه واقعی، تصویر شاخص eager/high، شرح کامل پروژه، کارت مشخصات sticky دسکتاپ و CTA. موبایل تک‌ستونه است؛ مشخصات دو ستونه و در عرض بسیار کم تک‌ستونه می‌شود. CSS فقط در صفحه zc_project enqueue می‌شود و offset نوار مدیریت را لحاظ می‌کند.
- مقادیر ساختگی fallback مانند کارفرمای فرضی، تاریخ/مدت فرضی و «۳۲۰٪ رشد» حذف شدند؛ فقط متادیتای واقعاً ثبت‌شده نمایش داده می‌شود. هیچ داده‌ای از DB حذف نشده است.
- لینک بیرونی فقط http/https با noopener/noreferrer است؛ CTA درخواست پروژه به صفحه تماس با شناسه پروژه می‌رود. پروژه رمزدار پیش از تصویر/متادیتا فقط فرم رمز را نشان می‌دهد. محتوا، wp_link_pages و ابزارهای قبلی Single_Experience حفظ شده‌اند. تصویر نداشته باشد placeholder غیرتصویری نشان داده می‌شود، نه عکس یا نتیجه جعلی.

## شواهد

- `qa-project-template.php`: رندر واقعی فایل PHP قالب با WP API doubles؛ fixture دیتابیس یا اجرای کامل WordPress نیست.
- `qa-project-layout.cjs`: **۶۹ assertion مرورگر واقعی Chromium 133** در عرض‌های ۳۲۰، ۳۵۹، ۳۹۰، ۴۳۰، ۷۶۸، ۱۰۲۴، ۱۴۴۰؛ بدون overflow صفحه، تصویر محدود، یک H1، sticky/normal sidebar، تک‌ردیفه بودن و ارتفاع/اسکرول/لمس‌پذیری فیلترها، انتخاب فیلتر و بازگشت همه کارت‌ها با کنترلر legacy واقعی. screenshot موبایل بررسی شد؛ عکس پروژه در fixture SVG ساده است، نه تصویر واقعی پروژه.
- contract PHP: ۳۱۱ assertion و syntax در ۸۹ فایل runtime؛ آزمون مجزای قالب و fixture نیز lint شدند.

آزمون کامل WordPress/Elementor/WooCommerce، سایت زنده، داده همه پروژه‌های کاربر، PageSpeed، SEO Rich Results یا بازگشت پیکسل‌به‌پیکسل به مرجع داخلی قبلیِ ناموجود تأیید نشده است. تست مرورگر فیلتر legacy را اجرا می‌کند؛ handler زنده Elementor در این fixture نصب نیست. فونت و header/footer زنده در fixture کامل بازسازی نشده‌اند.

قالب و companion با نسخه یکسان rc.6 بسته‌بندی می‌شوند؛ موتور WebP/Lazy و طراحی درون‌ریز این چرخه تغییر عملکردی نکردند. برای اعمال ظاهر جدید نیازی به درون‌ریزی دمو نیست؛ پس از به‌روزرسانی، کش صفحه/مرورگر و CSS تولیدی المنتور پاک شود.
