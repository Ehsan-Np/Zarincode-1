# ری‌دیزاین صفحات داخلی خدمات و نمونه‌کارها — v4.2.0 (۲۰۲۶-۱۱-۰۱)

**الزام کاربر:** طراحی صفحات داخلی «توضیحات خدمات» و «نمونه‌کارها» از صفر، دقیق و جذاب؛ ری‌دیزاین کامل طرح فعلی.

**تحقیق (الزام دستوری):** ساختار صفحات خدمات و کیس‌استدی برندها (Hero نتیجه‌محور + trust bar + شفافیت قیمت + Process + FAQ + CTAهای تکرارشونده؛ کیس‌استدی: مشخصات متا + نتیجهٔ شاخص + روایت چالش/راه‌حل + فکت‌شیت + لینک زنده).

## ساختار جدید — `single-zc_service.php`
Breadcrumb → هیرو تیرهٔ سینمایی (آیکون، عنوان فارسی/انگلیسی، چیپ‌های اعتماد، CTA دوگانه) + کارت قیمت (قیمت قدیم، تخفیف روبانی، نکات سبز) → نوار ۴ آماری → فرم سریع درخواست (فیلدهای AJAX حفظ شد) → گرید ۸ وعدهٔ خدمت (آیکون+تن رنگی) → تایم‌لاین ۵ مرحله‌ای روند اجرا (از متا) → بدنهٔ مقاله‌ای → FAQ آکاردئونی (auto از متا) → CTA band → Single_Experience → نوار چسبان موبایل (قیمت+تماس).

## ساختار جدید — `single-zc_project.php`
Breadcrumb + کیکر CASE STUDY → هیرو تیره (عنوان، خط کارفرما/مجری، چیپ‌های متا) → بنر نتیجهٔ شاخص (metrics) → ۳ CTA (سفارش مشابه/مشاهدهٔ زنده/بازگشت) → دوستونه: روایت «داستان پروژه» + فکت‌شیت چسبان (۷ سطر + دکمه‌ها) → CTA band → Single_Experience → نوار موبایل.

## فنی
- CSS جدید شرطی: `assets/css/inner-pages.css` (enqueue فقط روی همین دو قالب) — RTL-first، حالت تاریک، `prefers-reduced-motion`، بدون JS اضافه (details/summary).
- همهٔ متا فیلدها، فرم AJAX (نام فیلدها/honeypot)، مودال `zc-consult-modal`، شمارهٔ برند و Single_Experience حفظ شدند — هیچ داده یا بخشی حذف نشده است.
- نسخهٔ ۴.۲.۰؛ تست: محیط واقعی WP (۶ خدمت + ۸ پروژهٔ دمو) — رندر کامل بدون هیچ Warning، اسکرین‌شات دسکتاپ+موبایل (همین پوشه).
