## ۳) معماری پنل فعلی (چه چیزی از قبل «سریع» هست)

1. **ویرایش زنده روی متن**: `Inline_Editing` از ویرایش درون‌خطیِ بومی Elementor استفاده می‌کند
   (`zc-inline-text` + تولبار Elementor؛ بدون autosave سفارشی). سریع‌ترین راه برای هر متنِ تکی.
2. **انتخابگر «کدام قسمت را ویرایش می‌کنید؟»** + **جستجوی کنترل** در بخش «ویرایش محتوا»؛ فیلتر پنل با
   کلاس‌های `zc-editor-group-*` روی کنترل‌ها انجام می‌شود (طبق توضیح کد: هرگز با condition —
   conditionها تنظیمات فعال را دور می‌ریزند).
3. **چهار تبِ محتوا**: متن / رسانه و نماد / پیوند / پیشرفته — فیلدها بر اساس نوع به تب می‌روند.
4. **حالت خودکار**: «منبع داده و نمایش خودکار» برای services/products/portfolio/blog (+تستیموشال)
   با انتخاب دسته، تعداد، مرتب‌سازی؛ اولین کارت دستی الگوی ظاهر است.
5. **ریپیترها با نام فارسیِ مشخص**: کارت‌های خدمات/مقالات/دیدگاه‌ها، پلن‌های طراحی وب‌سایت/سئو/محتوا و…
   با تب‌های داخل ردیف + `_variant` (ساختار محتوایی) + `_enabled`.
6. **استایل با قانونِ هدف‌مند**: یک ریپیترِ «استایل تمام اجزا» = (جزء موردنظر + شماره آیتم [۰=همه]) ×
   (تایپوگرافی/رنگ/پس‌زمینه/فاصله…) — یک قانون برای همهٔ آیتم‌های یک جزء.
7. **ساختار سفارشیِ دمو فقط با کد**: سِیدر/مدل‌ها (مسیر توسعه‌دهنده، نه پنل).

## ۵) سریع‌ترین روش ممکن (Playbook عملیاتی)

**مسیرهای سریع به ترتیب سرعت:**

1. **متنِ تکی/تیتر/دکمه**: کلیک روی متن در بوم → ویرایش درون‌خطی (بدون باز کردن پنل).
2. **هر محتوای دیگرِ یک ویجت**: کلیک ویجت → تب «محتوا» → بخش «ویرایش محتوا» → **«کدام قسمت؟» را
   انتخاب کنید** (برچسب‌ها اکنون توصیفی‌اند: «کارت معرفی آژانس ۱»، «عنوان اصلی ۱»، «TRANSPARENT PRICING
   تعرفه خدمات… (۳)») → یا سریع‌تر: **جستجوی کنترل** (نام فارسی کنترل را بنویسید).
3. **لیست/کارت‌های تکرارشونده**: همان بخش → ریپیتر با نام فارسی (کارت‌های خدمات، پلن‌های طراحی وب‌سایت…)
   → افزودن/کپی/حذف ردیف؛ داخل ردیف تب‌های محتوا/رسانه/پیوند/پیشرفته + `ساختار آیتم` + `نمایش آیتم`.
4. **دادهٔ خودکار (سایت/محصول/نمونه‌کار/مقاله)**: بخش «منبع داده و نمایش خودکار» → حالت «query» →
   دسته/تعداد/مرتب‌سازی. محتوای واقعی را از همان رکورد ویرایش کنید نه در پنل.
5. **استایل یک جزء برای همهٔ آیتم‌ها**: تب «استیل» → «استایل تمام اجزا» → یک قانون بسازید →
   «جزء موردنظر» + «شماره آیتم (۰=همه)» → تایپوگرافی/رنگ/پس‌زمینه/فاصله.
6. **ترکیب خانه**: hero = `zarincode_hero_intro` + `zarincode_products_slider` + `zarincode_hero_cta`
   (داخل `zc-hero-composition`)؛ نوار قیمت = `heading` + `zarincode_pricing` + ۳×
   `zarincode_pricing_plan` (داخل `zc-pricing-composition`) + `zarincode_service_matrix`.
7. **فقط توسعه‌دهنده (کد/JSON)**: پیش‌فرض‌های دمو (`Widgets/models/*.json`)، افزودن صفحهٔ جدید
   (`page_section_*`)، ترکیب سِیدر (`Demo_Seeder.php`)، سپس `tools/portable-demo-export.py`.
   پس از هر تغییرِ سِیدر: `php -l` + راستی‌آزمایی رندر + بازصادر WXR.

## ۶) بُردِ انجام‌شده در همین سایکل (سریع‌ترین بُردِ کدی)

**QW1 — تمیزکردن برچسب‌های انتخابگر (انجام‌شد):** در `Native_Design::model()` برچسب هر جزء اکنون:

- اگر `part_label` به **نامِ نقشِ واقعی** برسد همان می‌ماند («نشان بالای بخش ۱»، «عنوان اصلی ۱»، «کارت
  معرفی آژانس ۱»…)؛
- وگرنه از **برچسب واقعیِ درخت** (بدون پیشوندهای «بخش:/متن:/جزء:»، حداکثر ۴۶ کاراکتر + «…») استفاده می‌شود
  («TRANSPARENT PRICING تعرفه خدمات تخصصی زرین کد …» به‌جای «ناحیه چیدمان»)؛
- تکرارها با شماره (۲)، (۳) تمایز داده می‌شوند (رفعِ سه گزینهٔ یکسان).

راستی‌آزمایی: `wp eval` روی مدل‌های pricing/hero_intro — خروجی برچسب‌ها بالا نمونه‌آوری شد؛ `php -l` صفر خطا.

**بُردهای بعدی (پیشنهادی، نیازمند تأیید برای چرخهٔ بعد):**
- QW2: ریستِ خودکار انتخابگر به آخرین بخشِ ویرایش‌شده (کاهش کلیکِ تکراری).
- QW3: collapseِ پیش‌فرضِ تب «پیشرفته» و مخفی‌سازی `_visible`های خاموش از «همه اجزا».
- QW4: راهنمای «کجاست چیست؟» به‌صورت RAW_HTML در هر ویجت (لینک به همین سند).
- QW5: ابزارِ گزارشِ وابستگی «کدام متن از کدام مدل می‌آید» برای توسعه‌دهنده.
