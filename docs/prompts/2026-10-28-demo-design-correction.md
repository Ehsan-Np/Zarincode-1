# اصلاح برداشت از درخواست استانداردسازی متن

> دیزاین بخش درون ریزی دمو رو چرا خراب کردی؟ من فقط میخواستم متن هایی که نوشتی رو استاندارد سازی کنی

محدوده اصلاح: بازگرداندن ظاهر پیش از rc.4 (بنر، رنگ‌ها، کارت‌های آمار، فرم رادیویی، چیدمان دو ستونه و پنل محتوای دمو)، فقط با متن‌های کوتاه و استاندارد. قابلیت درون‌ریزی ۷۱ مقاله، ترمیم تصاویر، عدم تکرار و گزینه مستقل مقالات حفظ شود. استانداردسازی متن، مجوز بازطراحی رابط نیست.

کنترل انجام‌شده: CSS اصلی و styleهای inline با نسخه rc.3 مقایسه و حفظ شدند؛ بدنه منطق importer پس از render با rc.4 برابر است؛ فایل صفحه و آزمون PHP lint شدند. آزمون بصری مرورگر و اجرای مجدد ۵۸۷ assertion وردپرس این نوبت انجام نشد. این اصلاح سورس است؛ ZIPهای انتشار قبلی rc.4 بازنویسی نشده‌اند.
