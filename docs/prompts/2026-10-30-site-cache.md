# درخواست کاربر — پاک‌سازی کش

متن درخواست: «این امکان رو به قالب اضافه کن که بتونیم کش کل وبسایت وردپرسی رو پاک کنیم»

پیاده‌سازی: ابزار صریح پاک‌سازی کش‌های قابل‌دسترسی با پنل و نوار مدیریت، POST/nonce/مجوز مدیر، API افزونه‌های شناخته‌شده، گزارش تفکیکی، حفاظت چندسایتی و نسخه‌گذاری کش آفلاین. محدودیت کش مرورگر، CDN و هاست بدون اتصال صریح توضیح داده شود؛ دادهٔ مشتری و transientهای معتبر به‌طور کلی حذف نشوند. انتشار نهایی 4.0.3 بدون RC؛ سورس و بسته‌ها در GitHub.
