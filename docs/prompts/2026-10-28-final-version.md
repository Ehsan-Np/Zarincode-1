# درخواست انتشار نسخه نهایی

> تمام نسخه های rc  رو به نسخه نهایی تغییر بده و فایل نهایی رو در گیت هاب منتشر کن

نسخه فعال قالب، افزونه، رجیستری، منابع cache، نصاب، فایل‌های زبان و manifest با 4.0.0 یکسان می‌شوند. انتشار GitHub بدون پرچم prerelease و به‌عنوان latest انجام می‌شود. نامزدهای قدیمی با نسخه نهایی تجمیع/جایگزین می‌شوند، نه اینکه تاریخچه و لینک آرشیوشان تخریب یا شش انتشار یکسان دوباره ساخته شود. درخواست انتشار نهایی مجوز جعل وضعیت آزمون‌های فنی یا تجاری نیست.
