# ۲۰۲۶-۱۱-۰۹ — دستور دائمی پاک‌سازی: فقط پرامپت‌ها و آخرین نسخه بمانند (متن کامل کاربر)

> «حالا باید دستور دائمی من رو برای حذف فایل ها اجرا کنی و تمام فایل های اضافه و غیرضروری و بسته های نصبی اضافه رو حذف کن و فقط پرامپت ها و اخرین نسخه از افزونه باقی بمونه؛ میخوام هرچی که فایل اپلود کردم و هرچی که فایل اضافه هست رو کامل پاک کنی، آخرین نسخه قالب، آخرین نسخه افزونه و پرامپت های مورد نیاز برای کدنویسی رو نگه دار و تمام چیزهایی که اضافه هست رو به صورت کامل حذف کنی تا فضای ورک اسپیس خالی بشه.»

پاسخ‌های کاربر در همان پیام (انتخاب‌ها):
* بسته‌های نصبی ۴.۸.۰ (دو zip): **«پاک کن — فقط سورس بماند»**.
* دامنهٔ پاک‌سازی مستندات: **«حداکثر پاک‌سازی»** — فقط promptها، استاندارد کدنویسی و `AGENTS.md` می‌مانند.

اجرا: سورس فعال (`zarincode/`, `zarincode-core/`)، `docs/prompts/`, `docs/standards/`,
`uploads/Zarincode-Theme-Skill-v3.txt`، فایل‌های ریشه (`AGENTS.md`, `README.md`, `LICENSE`,
`ZARINCODE_DOCUMENTATION.md`, `.gitignore`, `.github/workflows/`) و `.git` می‌مانند.
سایر مسیرها با **sparse checkout** از worktree کنار گذاشته می‌شوند (در گیت و GitHub باقی می‌مانند):
`docs/audits/`, `docs/design/`, `docs/releases/`, `docs/adr/`, `docs/architecture/`, `docs/governance/`,
`docs/archive/`, `docs/*.md`, `tools/`, `deliverables/` (شامل zipهای ۴.۸.۰ که به‌درخواست کاربر
حذف فیزیکی شدند؛ چون track نشده‌اند قابل بازیابی نیستند و از سورس در چند ثانیه بازساخته می‌شوند).
کش‌ها و ابزارهای محلی (`.wp-cli/`, `.pki/`, `.config/`, `uploads/debug.log`, `/tmp`) پاک می‌شوند.
