# بازگردانی کامل به Zarincode 3.7.0 — ۲۰۲۶-۱۰-۲۲

کاربر پس از ارائه تصویر مرجع، صریحاً «کل قالب به ۳٫۷٫۰» را انتخاب کرد؛ بنابراین این بار بازگردانی فقط فایل صفحه محصول نیست.

## مبنا و محدوده
- مبنا: commit انتشار `7558e3a`، نه نسخه ۳٫۷٫۱ و نه بازگردانی جزئی ۳٫۸٫۱.
- تمام فایل‌های `zarincode/`، `zarincode-core/` و `tools/` از همان نسخه‌اند؛ فایل‌های افزوده‌شده بعدی در این سه مسیر حذف شده‌اند.
- هر پنج فایل `packages/` عین بسته‌های همان انتشار هستند.
- اسناد نگهداری، درخواست‌های کاربر، تصویر مرجع و تاریخچه Git حفظ شده‌اند. اسناد نسخه‌های جدیدتر، سابقه‌اند و به معنای فعال بودن تغییرات آنها نیستند.

## بررسی اجراشده
- برابری بایت‌به‌بایت تمام **۲۲۶ فایل قالب، ۶۶ فایل هسته و ۵ ابزار** با commit مبنا؛ نبود فایل اضافی در این سه مسیر.
- بررسی تک‌تک اعضای ZIP قالب و افزونه در برابر سورس بازگردانده‌شده: بدون فایل گمشده یا اضافی.
- صحت هر چهار checksum بسته‌ها/دمو/کیت.
- PHP lint برای **۸۱ فایل** و بررسی نحوی JavaScript اصلی؛ `git diff --check`.
- آزمون مرورگری جدید یا بررسی سایت زنده کاربر اجرا نشده است. تصویر ارسالی مرجع بازگردانی است، نه screenshot خروجی تست این مرحله.

## اعمال روی سایت
این تغییر روی مخزن و ZIP نصب انجام شده است؛ دسترسی به هاست/پیشخوان کاربر وجود ندارد. برای اعمال، از فایل‌ها و دیتابیس بکاپ بگیرید، هر دو ZIP قالب و هسته همراه ۳٫۷٫۰ را جایگزین کنید و کش Elementor، سایت/CDN و مرورگر را پاک کنید. درون‌ریزی دوباره دمو لازم نیست و ممکن است داده‌ها را تکراری کند.

تنظیمات ذخیره‌شده در دیتابیس یا قالب‌های اختصاصی Elementor روی هاست با تغییر سورس خودکار به عقب برنمی‌گردند. اگر سایت پس از جایگزینی فایل‌ها هنوز متفاوت بود، برای بررسی آن محیط، URL صفحه و نسخه‌های واقعاً نصب‌شده لازم است؛ نباید رفع مشکل روی سایت زنده را صرفاً از روی تغییر Git ادعا کرد.
