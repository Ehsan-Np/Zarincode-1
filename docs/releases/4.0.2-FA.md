# زرین‌کد 4.0.2 — طراحی یکپارچه ابزارک‌های بومی

انتشار نهایی بدون RC؛ ۲۰۲۶/۱۰/۳۰. قالب و هسته هر دو 4.0.2 هستند. تغییرات این نسخه در لایهٔ ارائه است؛ رفتار ویجت‌ها، AJAX، ثبت سفارش و اعتبارسنجی به وردپرس/المنتور/ووکامرس سپرده می‌شود.

## زبان طراحی
- استفاده از توکن‌های واقعی قالب و رنگ‌های تنظیم‌شده در Redux، نه یک پالت مستقل: زرد آفتابی، متن ذغالی، سطوح روشن/تیره و مرزهای ظریف.
- کارت‌های Bento، دکمه‌های گرد، فیلدهای هماهنگ، فاصله‌گذاری و تایپوگرافی فارسی، حالت hover/active/disabled/focus و پیام‌های موفقیت/خطا.
- RTL/LTR با خواص منطقی CSS، شبکهٔ محصولات واکنش‌گرا، فوکوس قابل دیدن و احترام به کاهش حرکت.

## پوشش کدنویسی

|---|---|
| وردپرس کلاسیک | جست‌وجو، آرشیو، دسته‌ها، برگه‌ها، متا، فهرست ناوبری، نوشته‌ها/دیدگاه‌های اخیر، RSS، تقویم، ابر برچسب، متن/HTML، تصویر، گالری، صوت و ویدئو |

| المنتور بومی | عنوان، متن، دکمه، تصویر/کپشن، ویدئو، SoundCloud، نقشه، Text Path، جداکننده، آیکون و باکس آیکون/تصویر، فهرست آیکون، شمارنده، پیشرفت، امتیاز، نظرات، آکاردئون/Toggle/Tabs قدیمی و Nested، شبکه/کاروسل تصویر، شبکه‌های اجتماعی و Alert |

| ووکامرس کلاسیک | فهرست محصولات و نظرات، دسته/برچسب، قیمت و فیلتر ویژگی/امتیاز/فیلترهای فعال، جست‌وجو و مینی‌کارت؛ کاتالوگ، صفحه‌بندی، فرم‌ها، پیام‌ها، جدول سبد، تسویه و حساب؛ تب‌های محصول/نظرات و قواعد ویجت‌های محصول المنتور |

HTML، Shortcode، Anchor، Spacer، Inner Section و Sidebar المنتور نباید یک کارت اجباری یا عرض ثابت بگیرند؛ وظیفه‌شان نگهداری ساختار/خروجی دلخواه است. برندهای شبکه اجتماعی و نسبت تصویر ویدئو حفظ می‌شوند. این تصمیم بخشی از پوشش ایمن است، نه تلاش برای بازنویسی محتوای دلخواه افزونه‌ها.

## تنظیمات و نصب
1. پشتیبان بگیرید؛ قالب و هسته 4.0.2 را جایگزین کنید. قالب فرزند، uploads و محتوای سایت حذف نشوند.
2. در تنظیمات قالب ← ماژول‌های ابزارک، سه کلید مستقل «طراحی اختصاصی ابزارک‌های وردپرس»، «طراحی اختصاصی ویجت‌های بومی المنتور» و «طراحی اختصاصی ابزارک‌ها و اجزای ووکامرس» پیش‌فرض روشن‌اند.
3. کش صفحه/CDN را پاک کنید؛ در صورت استفاده از المنتور، فایل‌های CSS آن را بازتولید کنید. **درون‌ریزی یا ریست دمو لازم نیست.**
4. رنگ‌ها از توکن‌های تنظیمات قالب پیروی می‌کنند. تنظیم اختصاصی هر ویجت المنتور با CSS تولیدشدهٔ معمول، به‌علت specificity بالاتر بر پیش‌فرض‌ها اولویت دارد؛ در CSS جدید از `!important` استفاده نشده است.

استایل وردپرس برای ابزارک‌هایی که خارج از صفحات تکی و در ناحیه‌های جانبی یا قالب‌ها هستند هم بارگذاری می‌شود. استایل ووکامرس با فعال‌بودن آن، حتی بیرون مسیر shop، برای مینی‌کارت قابل استفاده است. شرط محدودکنندهٔ قدیمیِ singular برای استایل المنتور حذف شد تا قالب‌ها و آرشیوهای آن را جا نیندازد. پنل مدیریتی/پوستهٔ ویرایشگر بازطراحی نشده است.

## شواهد و محدودهٔ تأیید
[گزارش آزمون و دستور بازسازی](../audits/2026-10-30-NATIVE-WIDGET-DESIGN-FA.md): ۱۸ بررسی وردپرس واقعی ۶.۸.۳، ۲۰ قرارداد hook/کلیدها، ۱۳۲۴ بررسی CSS/selector/مرورگر در ۲۴ ترکیب عرض/جهت/حالت، با دو منبع نمونه (HTML ثابت و خروجی شش ابزارک واقعی وردپرس). آزمون‌های عمومی قرارداد و syntax نیز موفق بودند.

این اعداد گواه اجرای تراکنش واقعی یا همه ویجت‌های همه نسخه‌های Elementor/Pro/WooCommerce نیستند. در این نوبت خود Elementor/WooCommerce نصب نشدند؛ نمونه‌های آن‌ها HTML نمایندهٔ کلاس‌های عمومی‌اند. پرداخت واقعی، Select2/AJAX، همه پنجره‌های بازشو و تعامل داخل iframe ویرایشگر نیاز به آزمون روی staging با نسخه‌ها و درگاه‌های نصب‌شده دارند. مجوزهای تجاری و دروازه‌های باز قبلی همچنان باز هستند.
