# 4.0.0-rc.5 — یکپارچگی رسانه دمو، WebP و Lazy load

قالب و companion هر دو به‌روز شوند؛ تغییر فقط افزونه یا فقط قالب توصیه نمی‌شود. ظاهر قبلی درون‌ریز حفظ شده است. نسخه پیش‌انتشار است؛ تأیید کلی همه افزونه‌ها یا انتشار تجاری ادعا نمی‌شود.

پس از پشتیبان‌گیری، برای سایت دارای دمو «مقالات و تصاویر شاخص» و سپس «ترمیم تصاویر دمو» را اجرا کنید. لازم نیست برای اصلاح تصویر کل تنظیمات یا چیدمان صفحات را دوباره وارد کنید. برای سایت تازه، دموی کامل این مسیر را خودکار استفاده می‌کند.

تصاویر محلی از همان موتور WebP و کتابخانه رسانه وردپرس عبور می‌کنند؛ URL/id نهایی در دمو ذخیره می‌شود. فیلتر خالی‌کننده HTML مانع ثبت thumbnail معتبر نمی‌شود. temp داخل uploads و خطای واقعی میزبان با کد و نام فایل گزارش می‌شود، نه ۷۱ پیام تکراری. WXR دیگر تصاویر را از شاخه main گیت‌هاب دانلود نمی‌کند.

Lazy load بومی برای IMG در خروجی سایت به‌طور پیش‌فرض روشن است؛ لوگو/تصاویر eager و high-priority مستثنا هستند. تنظیمات WebP/Lazy هنگام درون‌ریزی کامل حفظ می‌شوند. منابع اصلی قالب حفظ می‌شوند؛ فقط کپی آپلودشده مطابق سیاست موتور تبدیل می‌شود. only-smaller پیش‌فرض و نبود codec/MIME می‌تواند به حفظ JPEG/PNG منجر شود، نه خرابی دمو.

[گزارش آزمون و محدودیت‌های دقیق](../audits/2026-10-28-DEMO-WEBP-LAZY-FA.md).

ZIPها در `packages/candidates/media-4.0.0-rc.5/` آرشیو و لینک commit ثابت در GitHub Release درج می‌شوند. manifest commit سورس، CRC و hash بسته‌های نصب را ثبت می‌کند؛ انتشارهای قبلی دست‌نخورده‌اند. فایل‌های ZIP پیوست uploadشده Release نیستند و از آرشیو مخزن دریافت می‌شوند.
