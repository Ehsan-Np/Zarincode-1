# زرین‌کد 4.0.0-rc.1 — تحویل نامزد انتشار بر اساس Skill 3.0.0

**این بسته نسخهٔ نهایی آمادهٔ فروش نیست.** تغییرات اجرا شده‌اند، اما همهٔ الزامات سند ۵۳‌بخشی و دروازه‌های تجاری آن تکمیل نشده‌اند. هیچ استثنای تأییدشده‌ای برای عبور از gate وجود ندارد. بسته برای ارزیابی و staging است؛ نام `rc.1` تأیید عبور از همهٔ مراحل مهندسی نیست.

## نصب و ارتقا

۱. از دیتابیس، uploads و هر دو بستهٔ قالب و افزونهٔ قبلی backup کامل بگیرید. ابتدا روی staging کار کنید.
۲. ZIP داخلی `zarincode-core-4.0.0-rc.1.zip` را از «افزونه‌ها ← افزودن ← بارگذاری» نصب/به‌روزرسانی و فعال کنید.
۳. ZIP داخلی `zarincode-4.0.0-rc.1.zip` را از «نمایش ← پوسته‌ها» نصب/به‌روزرسانی کنید. ZIP پروژهٔ بیرونی قابل نصب به‌عنوان قالب نیست.
۴. Elementor/Redux را جداگانه نصب کنید. Pro، WPML و هر افزونهٔ تجاری فقط با مجوز خود خریدار نصب می‌شوند؛ در این تحویل باندل نشده‌اند.
۵. از پنل یکپارچه، وضعیت افزونه‌ها و «سلامت و عیب‌یابی» را ببینید. پس از backup کش CSS Elementor را بازسازی و صفحه‌های موجود را بررسی کنید. برای ارتقا دمو را دوباره وارد نکنید.
۶. قالب دیگر companion را خودکار نصب یا بازنویسی نمی‌کند. نبود companion باعث ناپدیدشدن محتوا از پایگاه داده نمی‌شود، ولی CPT و ویجت اختصاصی تا فعال‌سازی دوباره ارائه نمی‌شوند.

برای rollback، **هر دو بستهٔ قبلی** و در صورت نیاز backup دیتابیس را بازیابی کنید؛ برگشت فقط قالب یا فقط افزونه، به‌خصوص با installer قدیمی، راهبرد ایمنی نیست. هیچ مهاجرت دسته‌ایِ خودکاری روی Elementor data اجرا نشده است.

## تغییرات

- حذف اولویت EmbeddedCore قالب و کپی خودکار فایل‌های افزونه؛ مالکیت واقعی کلاس‌ها در companion.
- `functions.php` پنج‌خطی و bootstrap مستقل presentation؛ نام‌های عمومی قبلی helperها حفظ شدند.
- حذف سورس تکراری فقط پس از اثبات برابری آن با companion؛ تاریخچهٔ گیت باقی است.
- قرارداد افزودنی برای هر ۲۶ ویجت، schema version، بودجهٔ هدف و وضعیت کیفیت نامشخص به‌جای نمرهٔ ساختگی.
- API opt-in نسخه‌بندی تنظیمات با حفظ فیلد ناشناخته و `_id`؛ idempotence و رد نسخهٔ آینده آزموده شدند. این API هنوز به معنی مهاجرت کامل همهٔ ویجت‌ها نیست.
- عیب‌یابی محافظت‌شده و اطلاعات محدود Site Health، بدون افشای تنظیمات خام یا مشتریان.
- کنترل مجوز و whitelist عملیات installer؛ درخواست activate بدون نصب، اجازهٔ دانلود ضمنی ندارد.
- Elementor Pro در manifest اختیاری است؛ URL نصب خودکار بسته‌های تجاری مربوط حذف شد.
- توقف بارگذاری مجموعهٔ کلاس‌های ویجت وقتی خانوادهٔ پایه خاموش است.
- سقف query عمومی ۱۰۰ رکورد؛ انتخاب قبلی «همه» اکنون در UI صریحاً سقف ۱۰۰ دارد. داده حذف نمی‌شود؛ pagination مجموعه‌های بزرگ هنوز کار باز است.
- آزمون قرارداد و معماری، تست استقلال روی WordPress واقعی و CI بدون job انتشار خودکار.

قالب محصول، سایدبار، ترکیب کارت‌ها و فایل‌های CSS/JS تأییدشدهٔ ظاهر تغییر نکرده‌اند. اثبات یکسان‌بودن بایت فایل‌های ارائه با بازبینی بصری کامل یکسان نیست.

## مالکیت، مجوز و وابستگی‌ها

فونت‌ها و تصاویر مخزن طبق درخواست شما حفظ شدند. هدر Font Awesome Pro 7.3.1 مجوز تجاری ذکر می‌کند؛ حق بازتوزیع در محصول مارکت هنوز اثبات نشده است. مجوز GPL کد زرین‌کد، خودبه‌خود مجوز Font Awesome Pro یا رسانه‌های ثالث نیست. این بسته اجازهٔ تجاری تازه‌ای برای آن دارایی‌ها ایجاد نمی‌کند.

Core/Pro/Redux/Woo نصب‌شدهٔ QA صرفاً برای آزمون‌اند و داخل بسته نیستند. Pro از همان commit و hash ثبت‌شدهٔ مخزن معرفی‌شدهٔ شما دریافت شد؛ تطابق hash اثبات اصالت ناشر نیست. هیچ تغییر یا دورزدن سیستم لایسنس انجام نشد.

## کارهای بازِ مانع نسخهٔ نهایی

- بررسی و استایل و شواهد editor/frontend/RTL/LTR/a11y/visual تک‌تک ۱۹۴ ویجت غیر اختصاصی نصب‌شده؛ موجودی‌برداری کافی نیست.
- کنترل‌های مرتبط کامل، Dynamic Tags، parity و امتیاز واقعی Z-WQI حداقل ۹۰ برای ویجت‌ها.
- همهٔ سرویس‌های اختیاری زیر Feature Manager، نه فقط سه خانوادهٔ ویجت.
- TGMPA واقعی، gettext کامل و آزمون‌های WPML/add-onها و adapter مستقل Polylang.
- ماتریس Woo برای انواع محصول، HPOS، Store API، cart/checkout blocks و سناریوهای مجوز/پرداخت.
- ممیزی کامل امنیت، WCAG 2.2 AA و screen reader، visual regression، بودجه‌های اندازه‌گیری‌شده، CWV میدانی و تست‌های بار.
- PHPCS/WPCS، PHPStan Level 10 برای کد جدید، lintهای JS/CSS و اندازه‌گیری پوشش بحرانی ۸۰٪؛ syntax check جایگزین این‌ها نیست.
- وابستگی رسانه/توکن برخی رندرهای قدیمی به دارایی قالب و وجود منطق قدیمی در presentation باید بازبینی شود.
- مجوز تمام دارایی‌ها، مستندات کامل خریدار، فرآیند update امن، بازبینی انسانی و تأیید انتشار تجاری.

هر ردیف باز در `docs/governance/skill-v3-tasks.json` و وضعیت صریح گیت‌ها در گزارش انطباق ثبت شده است. نسخهٔ پایدار 3.7.5 خودکار جایگزین نشده و هیچ استقرار روی سایت اصلی انجام نشده است.

## شواهد همین نسخه

- ۹۴ assertion خالص قرارداد/schema و ۹ قاعدهٔ معماری محدود موفق شدند.
- ۴۰ assertion یکپارچگی روی دیتابیس واقعی و ۲۴ assertion زیرساخت اجرا و موفق شدند؛ اجرای نهاییِ دارای Pro هنگام پاک‌سازی fixture خطای نبود جدول notes داد، بنابراین کل چرخهٔ Pro «بی‌خطا» یا کامل اعلام نمی‌شود.
- ۲۴ ترکیب Chromium (خانه، بلوک، محصول و خدمت × سه عرض × RTL/LTR) موفق شدند. خاموشی ویجت‌ها خروجی و assetهای اختصاصی بررسی‌شده را صفر کرد.
- ۷۱ فایل PHP syntax-check شدند؛ گزارش نتیجه، نسخه‌ها و محدودیت‌ها در `docs/audits/skill-v3/` است.
- درخواست‌های مستقل پس از تعویض قالب و غیرفعال‌سازی افزونه ثبت شدند.
- امتیاز Z-WQI، پوشش ۸۰٪، WCAG و full official-widget coverage اندازه‌گیری/تأیید نشده‌اند.
- ابتدا محیط فارسی QA به علت مسدودشدن دانلود ترجمه LTR بود؛ آن اجرای نامعتبر کنار گذاشته و پس از نصب pack فارسی و guard تشخیص locale، همهٔ ۲۴ حالت مجدداً اجرا شدند.

هشدار PHP 8.4 دربارهٔ nullable parameter در Elementor و خطای جدول notes در پاک‌سازی fixture Pro ثبت شد. نیاز به تکمیل setup/migration افزونهٔ Pro و بازآزمایی وجود دارد؛ فایل افزونهٔ ثالث دست‌کاری نشده است.
