# زرین کد 4.0.0 — انتشار نهایی

به درخواست صریح کاربر، همه بخش‌های فعال قالب و افزونه از شماره RC به **4.0.0** یکسان شدند. انتشار GitHub نهایی است: `prerelease=false` و latest. این نسخه شامل آخرین اصلاحات دمو، تصاویر/WebP، Lazy load، تنظیمات و نمونه‌کارهاست؛ هیچ قابلیت قبلی صرفاً به دلیل تغییر شماره حذف یا بازنویسی نشده است.

## نصب

ابتدا از فایل‌ها، uploads و دیتابیس پشتیبان بگیرید. بسته `zarincode-4.0.0.zip` را برای قالب و `zarincode-core-4.0.0.zip` را برای افزونه هسته نصب کنید؛ هر دو باید به‌روز شوند. WordPress نسخه 4.0.0 را جدیدتر از 4.0.0-rc.6 می‌شناسد. شماره cache و نصاب هسته نیز هماهنگ است. پس از نصب، کش سایت/مرورگر و CSS تولیدی المنتور پاک شود.

برای تغییر نسخه یا اعمال ظاهر نمونه‌کار، درون‌ریزی مجدد لازم نیست. اگر رسانه دمو ناقص است، فقط «مقالات و تصاویر شاخص» و «ترمیم تصاویر دمو» را اجرا کنید؛ درون‌ریزی کامل می‌تواند تنظیمات نمایشی دمو را بازنشانی کند.

## فایل‌ها و تاریخچه

- `zarincode-4.0.0.zip`: قالب قابل نصب
- `zarincode-core-4.0.0.zip`: افزونه هسته قابل نصب
- `ZarinCode-4.0.0-project.zip`: سورس فعال، مستندات، ابزارها و دو بسته نصب
- `BUILD-MANIFEST.json`: commit دقیق سورس، SHA256 بسته‌های نصب و تأیید CRC/source parity

بسته‌ها در مسیر نسخه‌دار `packages/releases/4.0.0/` گیت‌هاب آرشیو و در متن Release با لینک commit ثابت ارائه می‌شوند. آپلود مستقیم asset در محیط پیشین با EOF مواجه شده بود؛ پیوست آپلودشده ادعا نمی‌شود. نصاب افزونه از آرشیو tag ثابت v4.0.0 استفاده می‌کند. انتشارهای RC قبلی و شواهدشان تغییر نمی‌کنند و دیگر نسخه فعال نیستند.

## حدود تأیید

انتشار نهایی به درخواست کاربر است؛ با تأیید کامل تجاری/امنیتی یا همه ترکیب‌های WordPress/Elementor/WooCommerce یکسان نیست. gateهای انجام‌نشده و `commercial_approved=false` حفظ شده‌اند؛ فقط مجوز انسانی انتشار ثبت شده است. گاردهای بسته‌ساز دور زده نشده‌اند.

شواهد عملکردی قبلی در گزارش‌های [رسانه/WebP/Lazy](../audits/2026-10-28-DEMO-WEBP-LAZY-FA.md) و [نمونه‌کارها](../audits/2026-10-28-PORTFOLIO-FA.md) باقی‌اند. این چرخه تغییر شماره، هماهنگی فایل‌ها و بسته‌بندی است؛ آزمون زنده سایت یا کل ماتریس افزونه‌ها دوباره انجام نشده است.

## بررسی این چرخه

۳۱۱ assertion قرارداد PHP و syntax در ۸۹ فایل runtime، ۹۴ assertion مستقل، ۹ بررسی معماری محدود، ۶ تست نگهبان بسته‌ساز، ۴ تست بسته دمو و ۴ تست یکسانی نسخه نهایی موفق بودند. PHP نیز جدیدتر بودن 4.0.0 نسبت به rc.6 را تأیید کرد. metadata فایل‌های ترجمه کامپایل‌شده MO نیز نهایی شد؛ متن ترجمه‌ها بدون تغییر حفظ و مقایسه شد. هیچ تست عملکردی قبلی که این چرخه اجرا نشده باشد «اجرای تازه» معرفی نمی‌شود.
