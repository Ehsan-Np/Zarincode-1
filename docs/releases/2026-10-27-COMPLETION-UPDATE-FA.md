# به‌روزرسانی تکمیل کدنویسی — ۲۰۲۶/۱۰/۲۷ (ZarinCode 4.0.0-rc.2)

این سند، ادامهٔ [گزارش تحویل ۲۰۲۶/۱۰/۲۲](2026-10-22-DELIVERY-FA.md) است و فقط کارهایی را ثبت می‌کند که
**واقعاً در این چرخه کدنویسی/آزمون شده‌اند**. طبق دستور صریح کاربر، WPML خارج از دامنه است؛ هیچ ادعای
سازگاری WPML داده نمی‌شود و نبود آن، مانع پذیرش محسوب نمی‌شود. ترجمه‌های موجود، gettext و RTL/LTR دست‌نخورده‌اند.

## ۱. کارهای کدنویسی که در این مرحله تمام شد

### قالب (zarincode)
- **پالت پیش‌فرض Elementor:** کلاس `inc/Elementor/Kit_Defaults.php` با API رسمی Kit، فقط رنگ‌های
  **دست‌نخوردهٔ کارخانه‌ای** را جایگزین می‌کند: accent ‎#61CE70→‎#202227، primary ‎#6EC1E4→‎#1F6B8F،
  text ‎#7A7A7A→‎#5F6368 (همه با Luminance سازگار با متن سفید و استفاده روی زمینهٔ سفید، یعنی حداقل ۴٫۵:۱).
  انتخاب‌های سفارشی کاربر هرگز لمس نمی‌شود؛ اعمال یک‌باره و idempotent است.
- **کنتراست رسمی ویجت‌ها (`assets/css/elementor/official.css`):** رنگ پیش‌فرض کارخانه‌ای سفید روی
  سطوح آبی/سبز/تیل Elementor و Pro، توکن‌های Prism، لینک LostPassword حساب کاربری، دکمهٔ Tweet و
  کوپن شناور اصلاح شد. قواعد با specificity پایین‌تر از CSS هر نمونهٔ سفارشی‌شده نوشته شده‌اند تا
  انتخاب صریح نویسنده همچنان برنده باشد.
- **آبشار «ZC» تزئینی:** از متن قابل‌مشاهده به پس‌زمینهٔ SVG با `aria-hidden` تبدیل شد (حفظ ظاهر، رفع
  ایراد کنتراست متن تزئینی).
- **برخورد شناورها (`assets/js/zarincode-main.js`):** سوییچر Crextio، خوشهٔ `zc-floating-quick-contact`
  (شامل دکمهٔ بازگشت به بالا) و شناورهای اجتماعی به‌صورت خودکار از روی دکمهٔ شناور Contact Buttons و
  نوار Floating Bars Elementor فاصله می‌گیرند (رفع target-size موبایل).
- **نواحی اسکرول‌شوندهٔ کد:** `pre`های اسکرول‌شوندهٔ ویجت code-highlight با `tabindex` برای دسترسی
  صفحه‌کلید فعال می‌شوند (WCAG 2.1.1) و outline فوکوس دارند.
- بوت `Kit_Defaults` به `inc/Bootstrap/Theme.php` اضافه شد.

### ابزارهای آزمون (tools/)
- **قرارداد شکست-بستهٔ اسکن** (`widget-audit-contract.cjs` + ۶ تست Node): موارد غایب، تکراری، خارج از
  فهرست، خطای JS، جهت اشتباه، overflow، تخلف axe یا شکست fixture هرگز pass نمی‌شوند؛ امکان ادامهٔ
  اجرا از موارد ناموفق (`ZC_QA_RESUME=1`) با claim همزمان امن شغل‌ها.
- **Runner** با allowlist کنترل‌شده برای CDN داخلی Prism و ثبت خلاصهٔ ماشین‌خوان.
- **fixture جامع:** سوییچر `?qa_locale=` (mu-plugin محافظت‌شده)، ساختار Container برای ویجت‌های
  Floating (رفع ۲۸ خطای JS دستیار فروشنده)، پیوست تصویر با alt واقعی + لوگوی سایت، ردیف نشان
  اعتبارنامه، WAV محلی برای audio، فیلدهای معنادار شناورها و **اتصال واقعی label↔input برای
  فیلدهای اتمیک Elementor Pro** (`_cssid` + `input-id` داخل فرم `e-form`).
- **Runner تست صفحه‌کلید:** گزارش JSON ماشین‌خوان (`keyboard-report.json`) می‌نویسد.
- **Runner خرید مرورگر:** انتظار هیدریشن Blocks Checkout و گرفتن خطاهای `role=alert` اضافه شد.
- **`build-release.py` بازنویسی شد:** نسخهٔ بدون commit تمیز build نمی‌شود؛ فایل‌های secret/SQL/KEY،
  symlink و خروجی‌های تولیدی vendor/node_modules/__pycache__ رد می‌شوند؛ parity بایتی/CRC هر عضو؛
  گیت تجاری فقط با همهٔ gateها (استثنای WPML فقط همان دروازه را می‌پذیرد). **۶ تست** در
  `tools/test-build-release.py` این رفتار را پوشش می‌دهد.
- CI (`.github/workflows/engineering.yml`): تست‌های قرارداد اسکن، نصب ابزار مرورگر، تست کنتراست
  محصول، WooCommerce در job محتوای بحرانی و آپلود پوشش/شواهد.
