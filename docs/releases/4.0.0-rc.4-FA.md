# 4.0.0-rc.4 — اصلاح مقالات و تصاویر دمو

قالب و companion هر دو باید به‌روز شوند. بسته‌ها از سورس clean ساخته می‌شوند؛ manifest سورس دقیق و hash بسته‌های نصب را ثبت می‌کند. ZIPها در `packages/candidates/demo-4.0.0-rc.4/` آرشیو و لینک ثابت در GitHub Release درج می‌شوند؛ انتشارهای قدیمی دست‌نخورده‌اند. این نسخه پیش‌انتشار است و تأیید تجاری عمومی ندارد.

برای سایت دارای دمو، پس از پشتیبان‌گیری، بخش **«مقالات و تصاویر شاخص»** را در صفحه درون‌ریزی انتخاب کنید. این مسیر ۷۱ مقاله تخصصی را با دسته‌بندی و تصویر شاخص ثبت/ترمیم می‌کند، بدون بازنشانی تنظیمات و برگه‌ها. تکرار اجرا مقاله یا تصویر اضافه نمی‌سازد؛ نوشته عادی مشتری هم‌نام بازنویسی نمی‌شود. مقالات نشان‌دار دمو به‌روز می‌شوند. تصاویر چهار کاور محلی مشترک چرخشی هستند.

[جزئیات فنی و نتایج آزمون](../audits/2026-10-28-DEMO-REPAIR-FA.md). توضیحات اضافه به صفحه درون‌ریزی افزوده نشده‌اند؛ متن صفحه کوتاه و استاندارد شده است.
