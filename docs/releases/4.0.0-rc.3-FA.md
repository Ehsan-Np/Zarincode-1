# 4.0.0-rc.3 — تبدیل امن آپلودهای جدید به WebP

این پیش‌انتشار شامل ماژول WebP و تغییرات استانداردسازی ثبت‌شده پس از rc.2 است؛ انتشار قدیمی rc.2 همان نسخه تاریخی باقی می‌ماند. فایل قالب و companion باید هر دو به‌روز شوند. runtime فقط در companion قرار دارد.

- [راهنمای WebP و هشدار جایگزینی اصل](../WEBP-UPLOADS-FA.md)
- [شواهد واقعی و محدودیت‌ها](../audits/2026-10-28-WEBP-FA.md)
- [گزارش استانداردسازی قبلی](../audits/2026-10-28-SITE-STANDARDS-FA.md)

پیش از نصب پشتیبان بگیرید؛ تبدیل برای آپلودهای جدید به‌طور پیش‌فرض روشن است. فقط خروجی کوچک‌تر و معتبر جایگزین می‌شود. فایل اولیه پس از موفقیت نگهداری نمی‌شود. انیمیشن‌ها/وکتورها/فرمت‌های نامطمئن حفظ می‌شوند؛ تبدیل همه فرمت‌ها یا lossless بودن تضمین نشده است.

بسته‌ها با `tools/build-release.py` از درخت clean ساخته می‌شوند؛ `BUILD-MANIFEST.json` داخل بسته پروژه commit واقعی سورس، CRC/source parity و SHA256 فایل‌های نصب را ثبت می‌کند. مجوز تجاری/امنیت کامل/سازگاری همه افزونه‌ها تأیید نشده؛ `commercial_approved` همچنان false است.
