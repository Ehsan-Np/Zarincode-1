# زرین‌کد 4.0.0-rc.2 — بستهٔ کدنویسی‌شدهٔ به‌روز

این تحویل شامل کد اجرایی، سورس و ZIPهای نصب است؛ صرفاً پیشنهاد یا طرح توسعه نیست. **انطباق کامل Skill 3 و تأیید نهایی تجاری هنوز حاصل نشده است.** شماره RC برای پنهان‌نکردن همین وضعیت حفظ شده است.

## کدهای افزوده‌شده

- adapterهای مستقل WPML/Polylang برای ID نوشته و taxonomy و معرفی CPTها به Polylang؛ در حضور هم‌زمان دو موتور، adapterها متوقف و هشدار مدیریتی داده می‌شود. موتور ترجمهٔ جداگانه ساخته نشده است.
- نگاشت ترجمهٔ ۲۶ ویجت و ۹۵۳ فیلد متنی/فیلد repeater از کنترل‌های واقعی نصب‌شده استخراج شد. `_id`، انتخابگرها و تنظیمات فنی ترجمه نمی‌شوند. این XML به معنی آزمون کامل WPML واقعی نیست.
- Dynamic Tag بومی `zarincode-public-content` برای عنوان، خلاصه و دو فیلد عمومی مشخص. دسترسی به متای دلخواه، اطلاعات مشتری، محتوای پیش‌نویس، خصوصی و رمزدار وجود ندارد. سوییچ سیستم در همان پنل مشترک اضافه شد.
- کنترل مشترک native برای کادر/سایهٔ فوکوس و رنگ hover در هر ۲۶ ویجت؛ بدون مقدار پیش‌فرض که ظاهر تأییدشده را تغییر دهد. API کنترل با همان Elementor نصب‌شده بررسی شد؛ style-controlهای جداشدهٔ Elementor از API عمومی با ID خوانده شدند، نه دستکاری internals.
- استایل اختصاصی خانواده‌های مشخص heading/text/button/image/progress/accordion/tabs/form و چند خانوادهٔ دیگر؛ نمونهٔ واقعی heading/button آزموده شد. تمام ویجت‌های رسمی تأیید نشده‌اند. استایل فقط روی برگهٔ builder و هنگام فعال‌بودن سوییچ خودش بارگیری می‌شود؛ تنظیمات explicit المنتور اولویت بالاتری دارند.
- مدیریت واقعی پنجره‌ها: گردش Tab و Shift+Tab، Escape، بازگشت فوکوس، inert موقت پس‌زمینه و بازگرداندن وضعیت قبلی، shortcut جستجو و event delegation یک‌باره. handlerهای قدیمی تکراری حذف شدند.
- labelهای واقعی برای فیلدهای مودال، نام دسترس‌پذیر بستن/جستجو و اعلان status فرم. این تغییر هیچ endpoint ارسال سفارش یا تضمین تحویل پیام ایجاد نمی‌کند.
- invalidation تمام featureهای تغییرکرده و وابسته‌ها با یک بار پاک‌سازی cache Elementor؛ نه صرفاً اولین سوییچ.

## نصب

از دیتابیس و هر دو بستهٔ قبلی backup بگیرید و ابتدا staging را به‌روزرسانی کنید. ZIP پروژهٔ بیرونی را استخراج کنید؛ از پوشهٔ `install` ابتدا افزونهٔ `zarincode-core` و سپس قالب `zarincode` را نصب/به‌روزرسانی کنید. دمو را روی داده‌های موجود دوباره وارد نکنید. Elementor/Redux/Woo و بسته‌های تجاری جزو این تحویل نیستند. companion به‌صورت مستقل و صریح نصب می‌شود؛ بازگشت نسخه باید برای هر دو بسته انجام شود.

در ویرایشگر، کنترل‌های مشترک در بخش «حالت‌های فوکوس و تعامل» و Dynamic Tag در گروه ZarinCode قرار دارند. پنل مشترک همان `zarincode_opt` و همان منوی قبلی را نگه می‌دارد. شناسه‌های قبلی ویجت، CPT و repeater تغییر نکرده‌اند.

## نتایج واقعی این نوبت

- ۹۴ assertion خالص، ۹ قاعدهٔ معماری محدود، ۴۰ assertion یکپارچگی و ۲۴ assertion زیرساخت موفق.
- ۵۸ assertion کنترل مشترک و Dynamic Tag، از جمله نبود خروجی private/draft/password، موفق.
- ۲۴ assertion در fixtureهای adapter؛ **جای تست نصب واقعی WPML/Polylang نیستند**.
- ۹ بررسی صفحه‌کلید مودال و ۲۴ ترکیب responsive/RTL/LTR در Chromium موفق.
- بارگیری استایل و اعمال توکن واقعی دکمه در نمونهٔ heading/button موفق.
- ۷۵ فایل PHP syntax-check شدند؛ JSها syntax-check شدند. این‌ها PHPCS، PHPStan، پوشش ۸۰٪ یا ممیزی WCAG نیستند.
- Elementor 4.3.2 روی PHP 8.4 هشدار deprecated nullable نشان می‌دهد؛ فایل vendor تغییر نکرد. Pro در این revision مجدداً نصب/آزموده نشد؛ نتیجهٔ RC قبلی را به آن تعمیم نمی‌دهیم.

شواهد و سورس آزمون‌ها در `docs/audits/rc2/` و `tools/` موجود است. دو خطای fixture در حین توسعه (ساخت tag prototype بدون data و انتظار radius ثابت به‌جای توکن theme) اصلاح و تست درست مجدداً اجرا شد. اشکال label تکراری select نیز واقعاً در کد اصلاح و بررسی شد.

## آنچه مانع عنوان «نهایی آمادهٔ فروش» است

پوشش editor/frontend/visual/a11y همهٔ ویجت‌های رسمی و Z-WQI، تکمیل تمام قابلیت‌های registry، WPML/Polylang واقعی و Pro/Woo HPOS/blocks، تحلیل کیفیت و پوشش تست، ممیزی امنیت و WCAG، کارایی میدانی و مجوز تجاری دارایی‌ها همچنان بازند. فونت‌های مخزن حفظ شده‌اند؛ حق بازتوزیع Font Awesome Pro تأیید نشده است. هیچ استقرار روی سایت اصلی انجام نشد. فایل‌های قدیمی ممیزی در بسته، شواهد تاریخی‌اند و به‌عنوان آزمون این revision معرفی نمی‌شوند.
