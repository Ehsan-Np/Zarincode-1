# پژوهش و معماری شبکه‌ها و اعتبارنامه‌های ایرانی — ۳٫۴

## آیکون‌ها
هفت SVG شبکه‌های ایرانی از [persianlabs/icons](https://github.com/persianlabs/icons)، commit `c4db29f43a1ebaa0bfc1890a6bc64745457bc03f` دریافت شده‌اند. فایل MIT در `zarincode/assets/icons/persian/LICENSE.txt` همراه بسته است. SVGها فایل ثابت محلی‌اند؛ بارگذاری از CDN و فونت آیکون ایرانی اضافی وجود ندارد. این اجازه نرم‌افزاری جایگزین حقوق علامت تجاری شبکه‌ها نیست. آیکون شبکه‌های بین‌المللی از دارایی Font Awesome موجود قالب استفاده می‌کند.

## اشتراک محتوا با پیوند حساب برند یکی نیست
- Telegram: ساخت URL با `url` و `text` رمزگذاری‌شده مطابق [1](https://core.telegram.org/widgets/share).
- WhatsApp: `https://wa.me/?text=...` مطابق [1](https://faq.whatsapp.com/425247423114725/?cms_platform=iphone).
- X: `https://x.com/intent/tweet`، پارامترهای url/text مطابق [4](https://docs.x.com/x-for-websites/post-button/guides/web-intent).
- LinkedIn: لینک سبک `sharing/share-offsite/?url=...`، فقط URL؛ SDK بارگذاری نمی‌شود. [مرجع رسمی افزونه اشتراک](https://learn.microsoft.com/en-us/linkedin/consumer/integrations/self-serve/plugins/share-plugin). انتشار نهایی داخل حساب LinkedIn در این محیط آزمون نشده است.
- Facebook: لینک sharer بدون SDK؛ ارسال نهایی به حساب شبکه در این محیط آزمون نشده است.
- ایتا: [صفحه اشتراک روی دامنه رسمی](https://eitaa.com/share/url?url=https%3A%2F%2Fzarincode.com) واقعاً باز و لینک `et://msg_url` و مسیر وب مشاهده شد؛ خروجی قالب از همین HTTPS endpoint استفاده می‌کند.
- **بله، روبیکا و سروش پلاس:** در پژوهش حاضر endpoint عمومیِ مستند و قابل اتکای اشتراک وب احراز نشد. URL حدسی ساخته نشده است. دکمه با آیکون شبکه، انتخاب‌گر اشتراک دستگاه را باز می‌کند؛ کاربر برنامه نصب‌شده را انتخاب می‌کند. در مرورگر بدون Web Share، لینک کپی و نام مقصد در راهنما نمایش داده می‌شود. انتخاب خودکار یک برنامه خاص تضمین نمی‌شود.
- ایمیل از `mailto` استفاده می‌کند. لغو پنجره بومی خطا محسوب نمی‌شود؛ Clipboard با fallback انتخاب متن مدیریت می‌شود.

حساب‌های ایتا، بله، روبیکا، سروش، گپ، آی‌گپ و شاد از تنظیمات قالب قابل ثبت‌اند؛ ورودی خالی هیچ حسابی نمی‌سازد. پروفایل، URL قابل تنظیم است، نه آدرس حدسی مبتنی بر نام برند. پروفایل‌ها در پابرگ اصلی و با `[zarincode_social_links]` در ویجت Shortcode المنتور قابل نمایش‌اند.

## نشان‌های اعتبار: کد خام اجرا نمی‌شود
[مستند رسمی زرین‌پال](https://www.zarinpal.com/docs/extensions/official-logo) کد `https://www.zarinpal.com/webservice/TrustCode` را پیشنهاد می‌کند. در بررسی، این مسیر به `https://cdn.zarinpal.com/trustlogo/v1/trustlogo.js` هدایت شد. کد واقعی با `document.write` تصویر `https://cdn.zarinpal.com/badges/trustLogo/1.png` می‌سازد و `https://www.zarinpal.com/trustPage/` + hostname را باز می‌کند.

پیاده‌سازی ما **همان تصویر و پیوند استعلام** را به HTML عادی تبدیل می‌کند؛ document.write، اجرای کد دلخواه، popup وابسته به JS و SDK لازم نیست. ادعای تأیید شدن دامنه از پیش نمایش داده نمی‌شود؛ نتیجه نهایی در صفحه صادرکننده بررسی می‌شود.

[7](https://help.zibal.ir/article/how-get-and-set-up-online-payment-gateway/) دریافت کد نشان پس از تأیید درگاه را توضیح می‌دهد. صفحه API به مستندات client-rendered هدایت شد و کد فعلی نشان از آن احراز نشد؛ adapter اسکریپت حدسی برای زیبال ساخته نشده است. [راهنمای رسمی بیت‌پی](https://bitpay.ir/help-article-64-%D9%84%D9%88%DA%AF%D9%88%DB%8C-%D8%AA%D8%A7%DB%8C%DB%8C%D8%AF%DB%8C%D9%87-%D8%A8%DB%8C%D8%AA-%D9%BE%DB%8C) دریافت کد از «مدیریت درگاه ← لوگوی تأییدیه» را مشخص می‌کند.

### قرارداد فنی ورودی
1. ویجت مستقل **اعتبارنامه‌ها و نشان‌های پرداخت ایرانی** یک Repeater بومی دارد: صادرکننده، عنوان، کد رسمی، تصویر اختیاری و پیوند استعلام اختیاری.
2. HTML استاندارد دارای `<a href>` و `<img src>` تجزیه می‌شود. فقط URL و تصویر معتبر دوباره ساخته می‌شوند؛ متن خام هرگز echo نمی‌شود.
3. حالت رایج تصویر ساماندهی با `onclick="window.open('https://…')"` نیز فقط برای URL رشته‌ای HTTPS استخراج و به لینک عادی تبدیل می‌شود. تابع، عبارت JS یا بقیه handler اجرا نمی‌شود.
4. دامنه صادرکننده برای زرین‌پال، زیبال، آیدی‌پی، پی‌دات‌آی‌آر، پی‌پینگ، وندار، نکست‌پی، بیت‌پی، اینماد و ساماندهی محدود است. پروتکل خطرناک، HTTP خارجی، userinfo، پورت نامتعارف و دامنه مشابهِ جعلی رد می‌شوند. اعتبارنامه دیگر فقط پیوند HTTPS می‌پذیرد و مسئول انتخاب مرجع آن مدیر است.
5. برای کد صرفاً اسکریپتی غیر از adapter مشخص زرین‌پال، **تصویر رسمی و URL استعلام را از پنل صادرکننده بگیرید**. اجرای arbitrary JS راه‌حل سازگاری نیست. ممکن است تغییر فرمت رسمی نیازمند adapter جدید باشد.
6. تصویر، اندازه رزروشده، alt، lazy-loading و decoding async دارد. HTML سمت سرور ساخته می‌شود؛ هیچ استعلام HTTP سمت PHP و هیچ اسکریپت صادرکننده بارگذاری نمی‌شود. CSS فقط هنگام نیاز بارگذاری می‌شود.
7. **هزینه صفر مطلق نیست:** تصویر خارجی درخواست شبکه دارد؛ زمان سرور صادرکننده بیرون از کنترل قالب است. استفاده از تصویر محلی فقط در صورت اجازه صادرکننده مناسب است. lazy-loading ممکن است دانلود را تا نزدیکی viewport عقب بیندازد؛ اگر صادرکننده نمایش فوری الزام کرده، سیاست او را رعایت کنید.
8. لوگوی برند به‌تنهایی اعتبارنامه نیست؛ پیش‌فرض هیچ نشان صادرشده‌ای جعل نمی‌کند. پنل جای کلید محرمانه، توکن API یا Merchant secret نیست.

در پابرگ اصلی، کد اینماد/ساماندهی قبلی و فیلدهای جدید زرین‌پال/درگاه تکمیلی از همین renderer امن استفاده می‌کنند. برای چند نشان یا کنترل کامل‌تر، ویجت را در پابرگ المنتوری قرار دهید. نشان‌های قدیمیِ صرفاً اسکریپتی یا onclick غیررشته‌ای ممکن است تا تنظیم تصویر و URL نمایش داده نشوند؛ به اجرای ناامن برنمی‌گردند.
